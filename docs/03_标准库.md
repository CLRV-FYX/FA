全部函数按用途分类。所有示例都可直接运行。

## 1. 输出

| 函数 | 说明 |
|---|---|
| `print(a, b, ...)` | 打印任意个值，**空格分隔**，末尾换行 |
| `write(a, b, ...)` | 打印但**不换行、不加空格** |
| `println(a, b, ...)` | 同 `print` |

```fa
print("a", 1, 2.5, true)     # a 1 2.5 true
write("无"); write("空格")     # 无空格
```

## 3. 字符串（`str` 的方法）

```fa
let s = "  Hello, FA  "
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.len()` / `len(s)` | i64 | **字节**长度（UTF-8） |
| `s.bytes()` | i64 | 同 len |
| `s[i]` | char | 第 i 个**字节**（等价 `s.at(i)`）；越界报错。`str` 不可变，不能写 |
| `s.at(i)` | i64 | 第 i 个字节 |
| `s.slice(a, b)` | str | 取 [a, b) 子串（**字节**下标） |
| `s.char_len()` | i64 | **码点**个数（中文一个字符算 1，`len()` 算 3） |
| `s.char_at(i)` | i64 | 第 i 个**码点**；越界报错退出。码点 > 255 装不进 `char`，所以是 i64 |
| `s.codepoints()` | Vec<i64> | 全部码点（配 `chr()` 可以往返） |
| `s.slice_chars(a, b)` | str | 按**码点**取 [a, b) 子串（下标自动夹紧，不会切坏多字节字符） |
| `s.trim()` | str | 去掉首尾空白 |
| `s.upper()` / `s.lower()` | str | 大小写转换 |
| `s.find(sub)` | i64 | 子串位置，找不到返回 -1 |
| `s.contains(sub)` | bool | 是否包含 |
| `s.starts_with(p)` / `s.ends_with(p)` | bool | 前缀 / 后缀 |
| `s.replace(a, b)` | str | 替换所有 |
| `s.split(sep)` | Vec\<str\> | 切分 |
| `s.chars()` | Vec\<char\> | 切成字节数组 |
| `s.eq(t)` | bool | 内容相等 |
| `s.to_i64()` / `s.to_f64()` | i64/f64 | 转数字 |
| `s.repeat(n)` | str | 重复 n 次 |
| `s.count(sub)` | i64 | 子串出现次数 |
| `s.lines()` | Vec\<str\> | 按换行切分（自动去掉 `\r`） |
| `s.trim_start()` / `s.trim_end()` | str | 只去首部 / 只去尾部空白 |
| `s.to_str()` | str | 就是自己（与全局的 `str(s)` 等价）；任何类型都有 `to_str()` |
| `s.cstr()` | *u8 | 取 C 字符串指针（不加引用） |

```fa
print(s.trim())                 # Hello, FA
print(s.replace("FA", "世界"))   # "  Hello, 世界  "
print("a,b,c".split(",").get(2))# c
print(i64("123") + 1)           # 124
```

`s.bytes()` 是 `len()` 的历史别名（返回 i64，不是字节数组）；要字节序列用
`s.chars()`（`Vec<char>`，`char` 就是 u8），要码点用 `s.codepoints()`。

内建方法的**参数个数**在编译期查：`s.slice(1)`、`s.len(1)`、`v.get(0, 1, 2)`
都会报错并说明该给几个。

### 字符串全局函数

`str(x)` 把任意值转成文本（结构体、枚举、数组、容器都能转出可读形式）；
`chr(码点)` 把码点编成 UTF-8 字符串（`chr(20320)` 是「你」，`chr(65)` 是 `"A"`）；
`"文本{表达式}"` 做插值。

## 4. Vec\<T\>

```fa
let v = Vec<i64>[1, 2, 3]      # 创建（可为空：Vec<i64>[]）
let e: Vec<i64> = []           # 有类型标注时，空的 [] 就够了
```

结构体元素存在槽里的是**装箱指针**，所以 `v[0].字段` 直接可用；
`for s in v` 拿到的也是指向该元素的引用（改它会改到容器里的元素）。

| 方法 | 返回 | 说明 |
|---|---|---|
| `v.len()` | i64 | 元素个数 |
| `v.push(x)` | — | 尾部追加 |
| `v.pop()` | T | 弹出最后一个（空表会报错退出） |
| `v.get(i)` / `v[i]` | T | 按下标读（越界会报错退出；已内联，无调用开销） |
| `v.set(i, x)` / `v[i] = x` | — | 按下标写（越界会报错退出；已内联） |
| `v.contains(x)` | bool | 是否包含 |
| `v.index_of(x)` | i64 | 首次出现的下标，没有返回 -1 |
| `v.sort()` | — | 原地排序（数值 / 字符串都支持） |
| `v.reverse()` | — | 原地反转 |
| `v.join(sep)` | str | 拼接成字符串（元素会被 `to_str`） |
| `v.sum()` | 数值 | 求和 |
| `v.min()` / `v.max()` | 数值 | 最小 / 最大值 |
| `v.clear()` | — | 清空 |
| `v.resize(n, x)` | — | 改变长度，新增元素填 x |

**存储方式（性能相关）**：`Vec<T>` 按元素类型的实际宽度紧凑存放 ——
`bool / i8 / u8 / char` 每元素 **1 字节**，`i16 / u16` **2 字节**，`i32 / u32` **4 字节**，
其余（含 `i64 / f64 / f32 / str / 结构体 / 指针`）8 字节。
所以 `Vec<bool>` 一百万个元素只占 1 MB，而不是 8 MB。
对外传值仍然是 64 位（`uint64_t`），读写时自动做零扩展 / 符号扩展，
`Vec<i8>` 里的 `-1` 取出来还是 `-1`，`Vec<u8>` 里的 `255` 取出来还是 `255`。

```fa
let v = Vec<i64>[5, 3, 9]
v.sort()
print(v.get(0), v.min(), v.max(), v.sum())   # 3 3 9 17
let s = Vec<str>["香蕉", "苹果"]
s.sort()
print(s.join(" + "))                          # 橙子风格：按 UTF-8 字节序
```

```fa
v.push(4)
print(v.get(3))        # 4
for x in v: print(x)   # 遍历
```

## 5. Map\<K, V\>

```fa
let m = Map<str, i64>()                     # 空表
let m2 = Map<str, i64>["a": 1, "b": 2]      # 带初值的字面量
let e = Map<str, i64>[]                     # 空的字面量也行
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `m.set(k, v)` / `m[k] = v` | — | 写入 |
| `m.get(k)` / `m[k]` | V | 读取（不存在返回 0 / nil） |
| `m.has(k)` | bool | 是否存在 |
| `m.del(k)` | — | 删除 |
| `m.len()` | i64 | 键数量 |
| `m.keys()` / `keys(m)` | `Vec<K>` | 所有键（顺序不保证） |
| `m.values()` / `values(m)` | `Vec<V>` | 所有值 |
| `m.clear()` | — | 清空 |

```fa
m.set("苹果", 5)
print(m.get("苹果"), m.has("香蕉"))   # 5 false
for k in m: print(k, m.get(k))       # 遍历所有键
```

### 容器全局函数

方法都有对应的全局写法，两种等价（内部走同一份实现）：

| 全局写法 | 等价方法 |
|---|---|
| `len(x)` | `x.len()` —— 数组 / 字符串 / Vec / Map |
| `push(v, x)` / `pop(v)` | `v.push(x)` / `v.pop()` |
| `sum(v)` / `sort(v)` / `reverse(v)` | `v.sum()` / `v.sort()` / `v.reverse()` |
| `join(v, sep)` | `v.join(sep)` |
| `min(v)` / `max(v)` | `v.min()` / `v.max()`（标量的 `min(a, b)` 也照旧可用） |
| `contains(v, x)` | `v.contains(x)` |
| `keys(m)` / `values(m)` | —— 取出所有键 / 值，返回 `Vec` |

> 注意：`get` / `set` / `has` / `del` **只有方法（和下标）写法**，没有全局形式。

## 6. 数组 `[T; N]`

```fa
let a: [i64; 5] = [10, 20, 30, 40, 50]
print(a[0], a[4])      # 10 50
print(len(a))          # 5
for x in a: print(x)   # 遍历
```

数组是**值类型**，赋值会整体拷贝。需要共享时用指针：`let p = &a[0]`。

### 手动内存：`new` / `free`

`str` / `Vec` / `Map` 是引用计数的，出作用域自动释放，**不需要**也**不能** `free`。
只有 `new` 出来的（以及 C 那边 `malloc` 给你的）指针要自己还：

| 函数 | 说明 |
|---|---|
| `new 表达式` | 在堆上放一份拷贝，返回指针（`new Node { val: 1 }` → `*Node`） |
| `free(p)` | 先还掉 `p` 指向对象自己拥有的引用（结构体 / 枚举字段里的 `str`、`Vec`，数组元素），再把内存还给 malloc |

```fa
struct Node:
    val: i64
    name: str
    next: *Node

fn main() -> i64:
    let b = new Node { val: 2, name: "b", next: nil }
    let a = new Node { val: 1, name: "a", next: b }
    print(a.val, a.next.name)
    free(a)                        # 指针字段不是引用计数，两个节点各自 free
    free(b)
    return 0
```

只调 C 的 `free` 也能把内存还回去，但**不会**还字段引用 —— 结构体里的 `str` / `Vec`
就漏了。所以 FA 侧一律用内建 `free(p)`；`free` 只接受指针，给别的类型会编译报错。

assert(1 + 1 == 2)                 # 条件为假 → 报错并退出

## 9. Python 对象（`use py`）

| 方法 / 函数 | 说明 |
|---|---|
| `py.exec("代码")` | 执行一段 Python |
| `py.eval("表达式")` | 求值，返回 pyobj |
| `py.import("模块")` | `import`，返回模块对象 |
| `py.from_i64(n)` / `py.from_f64(x)` / `py.from_str(s)` | FA 值 → Python 对象 |
| `py.from_list(vec)` | FA 的 Vec → Python list |
| `obj.attr("名字")` | 取属性 |
| `obj.call(参数Vec)` | 调用（参数用 `Vec<pyobj>` 传） |
| `obj.to_str()` / `obj.to_i64()` / `obj.to_f64()` | 转回 FA 值 |

```fa
use py
fn main() -> i64:
    let math = py.import("math")
    let args = Vec<pyobj>[py.from_f64(9.0)]
    print(math.attr("sqrt").call(args).to_f64())    # 3.0
    return 0
```

## 10. Java 对象（`use java`）

| 方法 / 函数 | 说明 |
|---|---|
| `java.class("java.lang.Math")` | 查找类（支持点分写法） |
| `java.new(类, "构造签名", 参数...)` | 创建对象 |
| `java.call_i64(类, "方法", "签名", 参数...)` | 调用静态方法 |
| `java.call_f64(...)` / `java.call_obj(...)` / `java.call_void(...)` | 同上，返回类型不同 |
| `java.str("文本")` | FA 字符串 → Java String |
| `obj.jcall_i64("方法", "签名", 参数...)` | 调用**实例**方法 |
| `obj.jcall_f64` / `obj.jcall_obj` / `obj.jcall_void` | 同上 |
| `obj.to_str()` / `obj.to_i64()` / `obj.to_f64()` | 转回 FA 值 |

```fa
use java
fn main() -> i64:
    let m = java.class("java.lang.Math")
    print(java.call_i64(m, "max", "(II)I", 3, 7))       # 7
    let sb = java.new(java.class("java.lang.StringBuilder"), "()V")
    sb.jcall_void("append", "(Ljava/lang/String;)Ljava/lang/StringBuilder;", java.str("FA"))
    print(sb.jcall_obj("toString", "()Ljava/lang/String;").to_str())   # FA
    return 0
```
