# 第一部分 · 起步

## 1. FA 是一门什么样的语言

README 第一行写的是「**功能最全 + 速度最快**」，还有一句「能被零基础的人 30 分钟学会、
又能直接调用 C / C++ / Python / Java 一切生态的系统级语言」。落到实现上是这几件事：

- **直接生成 x86-64 原生机器码**（经 GNU as 汇编），不依赖 LLVM，不需要运行时虚拟机。
  `fa build x.fa -o x` 出来的就是一个普通的 Linux 可执行文件，`ldd` 只看到 libc。
- **自动内存管理**：编译期插入引用计数（不是 GC）。没有停顿，也不用手动 `free`；
  整数、浮点这些标量**一条引用计数指令都不插**。
- **缩进和花括号两种写法都认**，同一份文件里混着写也行。从 Python 来的写缩进，
  从 C / Java 来的写花括号。
- **一行 `use` 接进整个生态**：`use c "stdio.h"`、`use py`（内嵌 CPython，numpy/pandas/torch
  都能用）、`use java`（内嵌 JVM）、`use lib "./my.so"`（运行时 dlopen）。
- **报错是中文的**，带行号、列号、源码片段和插入符，编译期能查出来的绝不拖到运行时。

和你熟悉的语言对照一下：

| 你熟悉的 | FA 像它的地方 | FA 不像它的地方 |
|---|---|---|
| Python | 缩进、`print`、`len()`、`Vec`/`Map` 随手就用 | 静态类型、编译成机器码、快 6~160 倍 |
| C | 指针、数组、结构体、能直接调 C 库、能写内嵌汇编 | 自动内存管理、字符串和容器是内建类型 |
| Java | `impl` 像类的方法、枚举带载荷、有 `match` | 没有 JVM、没有继承、值类型是默认 |
| Rust | 枚举 + `match`、`defer`、`&` 取址 | 没有借用检查、没有 trait、没有泛型函数 |
| Go | `defer`、简单的语法、编译快 | 没有 goroutine、没有接口、有指针算术 |

**它现在不适合干什么**：需要闭包/泛型/trait 的抽象密集型代码、需要并发（还没有线程与
channel）、跨平台（后端只有 x86-64 Linux）。这些在 [第 29 节](#29-已知限制) 里逐条列清楚了。

## 2. 安装与第一次运行

### 2.1 装

```bash
git clone https://github.com/CLRV-FYX/FA.git
cd FA

# 方式一：把 fa 放进 PATH（推荐）
chmod +x bin/fa
export PATH=$PWD/bin:$PATH          # 想永久生效就写进 ~/.bashrc

# 方式二：装到 /usr/local/bin
./install.sh

# 方式三：什么都不装，直接用仓库里的启动器
bash bin/fa run hello.fa
```

需要的前置条件：**Python 3**（编译器本身是 Python 写的引导实现）、**gcc**（用来汇编与链接）、
**GNU as**（gcc 自带）。想跑 `use py` / `use java` 的示例还要 `python3-dev` 头文件 / JDK；
没有的话那两个测试会自动 SKIP，不影响别的。

验证装好了：

```bash
fa version
```

### 2.2 第一个程序

```bash
cat > hello.fa <<'EOF'
fn main() -> i64:
    print("你好, FA!")
    return 0
EOF

fa run hello.fa                     # 编译并立刻运行
fa build hello.fa -o hello && ./hello   # 或者编译成可执行文件再跑
```

### 2.3 命令一览

| 命令 | 作用 |
|---|---|
| `fa run x.fa` | 编译并立即运行 |
| `fa build x.fa -o out` | 编译为可执行文件 |
| `fa asm x.fa` | 只输出 x86-64 汇编：打到 stdout，并存一份 `x.s`（`-o` 可指定路径） |
| `fa check x.fa` | 只做语法/类型检查（不生成二进制，最快） |
| `fa tokens x.fa` / `fa ast x.fa` | 转储词法 / 语法树（自举比对用） |
| `fa version` | 版本 + Python/JVM 环境探测 |

常用选项：

| 选项 | 作用 |
|---|---|
| `-O 0..3` | 优化级别，默认 2（四个级别跑出来的结果完全一致，只有快慢差别） |
| `--emit-asm` | 额外导出汇编 |
| `-v` | 显示详细过程（编译到哪一步、用了哪些库） |
| `-k` | 保留中间产物（`.s`、`.o`），想读汇编时很有用 |

### 2.4 报错长什么样

编译期报错会指出**哪一行、哪一列、哪个名字**，并把那一行源码和插入符印出来：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    print(nope)
    return 0
```

```text
类型错误 (行 3, 列 11): 未定义的标识符 'nope'
        print(nope)
              ^
```

运行时错误同样明确（不是段错误糊脸）：越界、除零、空 Vec `pop`、`assert` 失败、`panic`
都有中文信息和非零退出码；真出了段错误，运行时也会先打印一句再退。详见
[第 18 节](#18-错误处理与运行时安全网)。

## 3. 程序的骨架

### 3.1 main 与退出码

程序从 `main` 开始。`main` 的返回值就是进程的退出码（`echo $?` 能看到），所以习惯上写
`return 0` 表示正常结束。

```fa
fn main() -> i64:
    print("这一句先执行")
    print("这一句后执行")
    return 0
```

```text
这一句先执行
这一句后执行
```

### 3.2 两种语法模式，可以混用

同一件事的两种写法，**语义完全一样**：

```fa
fn indent_style() -> i64:
    let x = 1
    if x > 0:
        return x
    return 0

fn brace_style() -> i64 {
    let x = 1;
    if (x > 0) {
        return x;
    }
    return 0;
}

fn main() -> i64:
    print(indent_style(), brace_style())
    return 0
```

```text
1 1
```

几个细节：

- 缩进模式里，`if` / `while` / `for` / `fn` 的头部以 `:` 结尾，下一行缩进就是它的内容。
- 花括号模式里分号 `;` 可写可不写，换行也是分隔符。
- **单行写法**两种模式都支持：`if x > 0 { return x }`、`while i < 3 { i += 1 }`。
- 一个「块」本身就可以当语句用，凭空开一层作用域（[第 4.5 节](#45-作用域与裸块)）：

```fa
fn main() -> i64:
    let total = 0
    {
        let tmp = 40          # 出了这个花括号 tmp 就没了
        total += tmp + 2
    }
    print(total)
    return 0
```

```text
42
```

### 3.3 注释

```fa
# 井号注释（Python 风格）
// 斜杠注释（C 风格）
fn main() -> i64:
    print("两种都行")     # 行尾注释也可以
    return 0
```

```text
两种都行
```

### 3.4 顶层能放什么

文件的最外层（不在任何函数里）只允许这几类声明：

| 声明 | 用途 | 章节 |
|---|---|---|
| `use ...` | 导入 C/C++/Python/Java，或另一个 `.fa` 文件 | [17](#17-多文件模块)、[19](#19-调用-c)、[20](#20-调用-c--python--java) |
| `fn 名字(...) -> 类型:` | 函数 | [8](#8-函数) |
| `struct 名字:` | 结构体 | [12](#12-结构体与方法) |
| `enum 名字:` | 枚举（可带载荷） | [13](#13-枚举与模式匹配) |
| `impl 名字:` | 给类型加方法 | [12](#12-结构体与方法) |
| `const 名字 = 值` | 编译期常量（不可变） | [16](#16-全局变量与-const) |
| `let 名字 = 值` | 全局可变变量 | [16](#16-全局变量与-const) |
| `extern` / `unsafe` | C 声明块 / 标记不做检查 | [19](#19-调用-c) |

写别的东西（比如顶层直接来一句 `print(...)`）会被明确拒绝：

```text
语法错误 (行 1, 列 1): 顶层只允许 use/fn/struct/enum/impl/const/let/extern 声明，得到 'print'
```

**顶层不是脚本**：FA 不像 Python 那样从上往下执行文件，所有可执行语句都得写在函数里，
程序从 `main` 开始。全局变量的初值是唯一例外 —— 它们在 `main` 的第一条语句之前执行一次
（[第 16 节](#16-全局变量与-const)）。

# 第二部分 · 语言基础

## 4. 变量、类型、作用域

### 4.1 let：声明一个变量

```fa
fn main() -> i64:
    let x = 10              # 类型自动推断成 i64
    let y: f64 = 1          # 显式标注：整数 1 会自动转成 1.0
    x = 20                  # 重新赋值不需要 mut（变量默认可改）
    let mut z = 1           # 写 mut 也接受，只是风格标注
    z += 5
    print(x, y, z)
    return 0
```

```text
20 1.0 6
```

FA 是**静态类型**的：每个值在编译期就有确定的类型，类型对不上当场报错，不会拖到运行时。
但类型大多能推断出来，所以你很少需要手写标注。

### 4.2 类型转换：`as`

```fa
fn main() -> i64:
    let n = 7
    let f = 3.9
    print(n as f64, f as i64, 65 as char, chr(66))
    print((n as f64) / 2.0, n / 2)
    return 0
```

```text
7.0 3 A B
3.5 3
```

- 浮点转整数是**截断**（`3.9 as i64 == 3`，不是四舍五入）；要四舍五入用 `round(x)`。
- 整数除整数还是整数：`n / 2 == 3`。想要 3.5 就得先 `as f64`。
- `整数 as char` 得到那个字节对应的字符（`65 as char == 'A'`），`chr(n)` 是同一件事的函数写法，
  而且 `chr` 会把 128 以上的码点编码成 UTF-8（`chr(20320)` 是「你」）。

### 4.3 基本类型

| 类型 | 说明 | 例子 |
|---|---|---|
| `i8 i16 i32 i64` | 有符号整数，默认 `i64` | `let n = 1` |
| `u8 u16 u32 u64` | 无符号整数 | `let b: u8 = 200` |
| `isize usize` | 与指针同宽的整数（= i64 / u64） | |
| `f32 f64` | 浮点，表达式里一律按 `f64` 算 | `let r = 1.5` |
| `bool` | `true` / `false` | |
| `char` | **一个字节**（u8），不是码点 | `'A'`、`'\n'` |
| `str` | 不可变字符串（UTF-8 字节序列） | `"你好"` |
| `*T` | 指向 T 的指针 | `*i64`、`*Node` |
| `[T; N]` | 定长数组，值类型 | `[i64; 3]` |
| `Vec<T>` | 动态数组，引用计数 | `Vec<i64>[1, 2]` |
| `Map<K, V>` | 哈希字典，引用计数 | `Map<str, i64>["a": 1]` |
| `fn(参数) -> 返回` | 函数指针 | `fn(i64) -> i64` |

`char` 是一个字节这件事很重要：`'A'` 是 65，而「你」在 UTF-8 里是 3 个字节，
装不进一个 `char`。要按「字符」处理中文，用 [第 6.5 节](#65-按码点处理中文) 的那组方法。

### 4.4 字面量

```fa
fn main() -> i64:
    print(42, -7, 1_000_000, 0xFF, 0b1010, 0o17)
    print(1.5, 1e3, 2.5e-2, -0.25)
    print(true, false, 'A', '\n' as i64, '\t' as i64)
    print("普通字符串", "带\"引号\"", "反斜杠\\")
    print(sizeof(i64), sizeof(f64), sizeof(bool), sizeof(char))
    return 0
```

```text
42 -7 1000000 255 10 15
1.5 1000.0 0.025 -0.25
true false A 10 9
普通字符串 带"引号" 反斜杠\
8 8 1 1
```

（第三行 `'\n' as i64` 打出来是 10、`'\t'` 是 9 —— 真的打印换行符会把输出搞乱，
所以这里转成整数看。）

整数支持 `_` 分隔（`1_000_000`）、十六进制 `0x`、二进制 `0b`、八进制 `0o`；
浮点支持科学计数法 `1e3`。`sizeof(类型)` 给出字节数。

### 4.5 作用域与裸块

变量的生命期到**它所在块结束**为止；引用计数的对象在那一刻自动释放。
花括号本身就是一条语句，可以凭空开一层作用域：

```fa
fn main() -> i64:
    let total = 0
    {
        let part = Vec<i64>[1, 2, 3]     # 出了块就释放
        total += sum(part)
    }
    let part = 100                        # 这里可以再叫 part，互不相干
    print(total, part)
    return 0
```

```text
6 100
```

### 4.6 遮蔽（shadowing）

内层作用域可以用同一个名字盖住外层，包括全局变量：

```fa
let name = "全局"

fn main() -> i64:
    print(name)
    let name = "局部"
    print(name)
    {
        let name = "块内"
        print(name)
    }
    print(name)
    return 0
```

```text
全局
局部
块内
局部
```

### 4.7 元组解构

FA 没有元组类型，但 `let` 支持一次绑定多个名字：

```fa
fn main() -> i64:
    let (a, b) = (1, 2)
    let (x, y, z) = (1.5, "文本", true)
    print(a, b, x, y, z)
    return 0
```

```text
1 2 1.5 文本 true
```

`let t = (1, 2)` 这种「把元组存进一个变量」是**不行**的（会报语法错误），
元组只出现在解构的右边。

### 4.8 这一节的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `print(7 / 2)` 打出 3 | 整数除整数向零截断 | 先 `as f64`，或用 `7.0 / 2` |
| `print(0.1 + 0.2)` 打出 0.3 | 打印按 %g 风格取有效数字，不是精确值 | 要精确比较用差值判小于 epsilon |
| `'你'` 报错或变味 | `char` 只有一个字节 | 用 `"你"`（str）或 `chr(20320)` |
| `let t = (1, 2)` 语法错误 | 没有元组类型 | 用多个变量，或用 `Vec` / 结构体 |
| 变量出了块就没了 | 块结束即释放 | 需要更长命就往外层声明，或用全局 |

## 5. 运算符与表达式

### 5.1 优先级

从松到紧：

| 级别 | 运算符 |
|---|---|
| 范围 | `..` `..=` |
| 逻辑 | `or` `and` |
| 按位或/异或/与 | `\|` `^` `&` |
| 相等 | `==` `!=` |
| 比较 | `<` `<=` `>` `>=` |
| 移位 | `<<` `>>` |
| 加减 | `+` `-` |
| 乘除取余 | `*` `/` `%` |
| 幂 | `**`（右结合） |

拿不准就加括号 —— 加了括号没人会扣分，算错了要查半天。

### 5.2 整数除法与取余：C 的语义

```fa
fn main() -> i64:
    print(7 / 2, 7 % 2, -7 / 2, -7 % 2, 7 / -2, 7 % -2)
    print(1 + 2 * 3, (1 + 2) * 3, 2 ** 10)
    return 0
```

```text
3 1 -3 -1 -3 1
7 9 1024
```

除法**向零截断**（不是向下取整），取余的符号跟着**被除数**走 —— 和 C 一致，和 Python 的
`//`、`%` 不一致（Python 的 `-7 % 2` 是 1）。从 Python 过来的人在这里最容易栽。

整数除以常量 0 在**编译期**就报错，不会等到运行时 SIGFPE。

### 5.3 浮点

```fa
fn main() -> i64:
    print(1 + 2.5, 3.0 * 2, 1.0 / 4, 0.1 + 0.2)
    print(1e20, 1.0 / 3.0, 100000.0, 0.000001, 3.9 as i64, round(3.9), floor(-3.2))
    return 0
```

```text
3.5 6.0 0.25 0.3
1e+20 0.33333333333333 100000.0 1e-06 3 4.0 -4.0
```

- 只要有一边是浮点，结果就是浮点（`1 + 2.5 == 3.5`）。
- 打印按 `%g` 风格：有效数字最多 14 位，很大/很小会切成科学计数法。
  `0.1 + 0.2` 打出来是 `0.3`（内部其实是 0.30000000000000004，打印时被有效数字截掉了）。
- `round` / `floor` / `ceil` 返回的是 **`f64`**（`round(3.9)` 是 `4.0` 不是 `4`），
  要拿去当整数用就再 `as i64`。
- 比较浮点**别用 `==`**：`abs(a - b) < 1e-9` 才是对的写法。
- 浮点除以 0 是 IEEE 754 的 `inf` / `nan`，属于合法运算，不报错。

### 5.4 比较与逻辑

```fa
fn main() -> i64:
    print(1 == 1, 1 != 2, 3 < 4, 4 >= 4, "a" < "abd")
    print(true and false, true or false, not true, !false)
    print(0 and 1, 5 or 0, !0, !7)
    return 0
```

```text
true true true true true
false true false true
false true true false
```

- `and` / `or` **短路**：左边已经决定结果就不算右边。
- `not` 和 `!` 是同一个意思，两种写法都行。
- `and` / `or` 的结果一律是 **bool**：整数操作数按「非零即真」判断，`0 and 1` 是 `false`、
  `5 or 0` 是 `true`（这点和 C/Python 不同，那两个语言会返回操作数本身）。
- `!` 作用在整数上得到 bool：`!0` 是 `true`，`!7` 是 `false`。按位取反是 `~`（`~12 == -13`）。

短路是可以依赖的语义，常用来省掉一次昂贵的判断：

```fa
fn expensive(tag: str) -> bool:
    print("  真的算了", tag)
    return false

fn main() -> i64:
    print(false and expensive("and 的右边"))
    print(true or expensive("or 的右边"))
    return 0
```

```text
false
true
```

（`expensive` 一次都没被调用，所以「真的算了」没有出现在输出里。）

### 5.5 位运算与移位

```fa
fn main() -> i64:
    print(12 & 10, 12 | 10, 12 ^ 10, ~12)
    print(1 << 10, 1024 >> 3, -8 >> 1)
    print(0xFF, 0b1010, 0o17, hex(255), oct(8), bin(5))
    return 0
```

```text
8 14 6 -13
1024 128 -4
255 10 15 ff 10 101
```

`>>` 对有符号数是**算术右移**（符号位复制），所以 `-8 >> 1 == -4`。
`hex` / `oct` / `bin` 返回**不带前缀**的字符串（`hex(255)` 是 `"ff"`），
要前缀就自己拼：`"0x" + hex(n)`。

### 5.6 复合赋值

`+= -= *= /= %= &= |= ^= <<= >>=` 都有，`x += 1` 就是 `x = x + 1` 的简写
（编译期会直接生成一条 `add`，不会多绕一圈）：

```fa
fn main() -> i64:
    let n = 10
    n += 5
    n *= 2
    n -= 4
    n /= 3
    n %= 7
    print(n)                       # 10+5=15, *2=30, -4=26, /3=8, %7=1
    let s = "a"
    s += "b"
    s += "c"
    print(s)
    return 0
```

```text
1
abc
```

FA **没有** `n++` / `n--`，写 `n += 1`。

### 5.7 char 参与算术：C 风格的整型提升

`char` 就是一个字节，参与算术时按 C 的规则提升成整数（结果是 `i64`），
所以大小写转换这类最常见的写法可以直接写：

```fa
fn to_lower(s: str) -> str:
    let out = ""
    for i in 0..s.len() {
        let c = s[i]
        out = out + (if c >= 'A' and c <= 'Z' { chr(c - 'A' + 'a') } else { chr(c) })
    }
    return out

fn main() -> i64:
    let b = 'H'
    print(b, b as i64, b - 'A', chr(b - 'A' + 'a'))
    print(to_lower("Hello, FA!"), "Hello".lower())
    print('9' - '0', 'a' - 'a' + 3)
    return 0
```

```text
H 72 7 h
hello, fa! hello
9 3
```

- `c - 'A' + 'a'` 这种算式的结果是 `i64`，要当字符用就再 `chr(...)` 一次。
- `'9' - '0' == 9` 是把数字字符转成整数的惯用法（整串转换用 `s.to_i64()`）。
- 内建的 `s.lower()` / `s.upper()` 只对 ASCII 生效（UTF-8 的大小写映射是个大坑，FA 没碰）。

### 5.8 if / match / 块 都能当表达式用

有返回值的写法，省掉一堆临时变量：

```fa
fn classify(n: i64) -> str:
    return if n < 0 { "负" } else if n == 0 { "零" } else { "正" }

fn grade(score: i64) -> str:
    return match score / 10:
        10: "满分"
        9: "优"
        8: "良"
        _: "继续努力"

fn main() -> i64:
    print(classify(-3), classify(0), classify(7))
    print(grade(100), grade(95), grade(83), grade(60))
    let n = if 3 > 2 { 10 } else { 20 }
    let big = if 3 > 2 { Vec<i64>[1, 2] } else { Vec<i64>[] }
    print(n, big, big.len())
    return 0
```

```text
负 零 正
满分 优 良 继续努力
10 [1, 2] 2
```

规则：

- 各分支的类型要能统一（`i64` 与 `f64` 会统一成 `f64`）；结构体、枚举、数组、`Vec`、`str`
  都能当分支结果。
- 以 `return` / `break` / `continue` / `panic` 结尾的分支算**发散**，不参与类型统一
  （所以 `if 找不到 { return -1 } else { 算出来 }` 是合法的）。
- `else` 不能省：当表达式用的 `if` 必须覆盖所有情况，否则「条件不成立时值是什么」没有答案。

### 5.9 字符串的运算符

`+` 是拼接，比较运算符按字典序（逐字节）比：

```fa
fn main() -> i64:
    let a = "abc"
    print(a + "def", a == "abc", a != "abd", a < "abd", a > "aaa")
    print(a.repeat(2), "abc".contains("b"), "abc".find("c"), "abc".find("z"))
    return 0
```

```text
abcdef true true true true
abcabc true 2 -1
```

（字符串没有 `* n` 这种「重复」运算符；重复用 `s.repeat(n)`。）

## 6. 字符串

### 6.1 字符串是不可变的 UTF-8 字节序列

```fa
fn main() -> i64:
    let s = "Hello, 世界"
    print(s.len(), s.char_len())
    print(s[0], s[7] as i64, chr(s[7] as i64))
    let t = s + "!"
    print(t, s == "Hello, 世界", s < "Hellp", s > "Hello")
    return 0
```

```text
13 9
H 228 ä
Hello, 世界! true true true
```

三件事必须记住：

1. **`len()` 数字节，不数字符。**`"Hello, 世界"` 有 9 个字符但 13 个字节
   （每个汉字占 3 字节）。数字符用 `char_len()`。
2. **`s[i]` 取的是第 i 个字节**，类型是 `char`（就是 u8）。`s[7]` 是「世」的第一个字节 228，
   把它当码点交给 `chr()` 得到的是 `ä`（U+00E4）—— 不是「世」。按字符取要用 `char_at()`。
3. **不可变。**拼接产生新字符串，原字符串不动。

不可变是编译器强制的，不是靠自觉：

```fa
fn main() -> i64:
    let s = "abc"
    s[0] = "x"          # ❌ str 不可变
    return 0
```

```text
类型错误 (行 3, 列 6): str 不可变（字面量放在只读数据段），不能按下标赋值；
需要可变的字符序列请用 Vec<char>
```

越界下标**能编译**（长度是运行时才知道的），但运行时会 panic 到 stderr 并以退出码 1 结束：

```fa
fn main() -> i64:
    let s = "abc"
    print(s[5])         # ❌ 越界
    return 0
```

```text
panic: 下标越界 (index out of range)：长度 3，下标 5
```

负数下标一样拦（`s[-1]` 报「长度 3，下标 -1」）—— FA 没有 Python 那种
「从末尾数」的写法，取最后一个字符是 `s[s.len() - 1]`。

### 6.2 字面量、转义、多行字符串

支持的转义（其他一律是编译错误，不会默默留下反斜杠）：

| 写法 | 含义 | | 写法 | 含义 |
|---|---|---|---|---|
| `\n` | 换行 (10) | | `\\` | 反斜杠 |
| `\t` | 制表 (9) | | `\"` | 双引号 |
| `\r` | 回车 (13) | | `\'` | 单引号 |
| `\a` `\b` `\f` | 响铃 (7) 退格 (8) 换页 (12) | | `\0` | 空字符 (0) |
| `\xNN` | 一个字节（2 位十六进制） | | `\uNNNN` | 码点（4 位十六进制，编成 UTF-8） |
| `\u{N...}` | 码点（位数不限，能写 emoji） | | `\{` `\}` | 见 [6.3](#63-插值) |

```fa
fn main() -> i64:
    print("换行:\n下一行")
    print("引号 \" 反斜杠 \\ 单引号 \'")
    print("\x41", "\u4F60", "\u{1F600}")
    print('\n' as i64, '\t' as i64, '\a' as i64, '\b' as i64, '\f' as i64, '\r' as i64, '\0' as i64)
    let m = """
第一行
    缩进原样保留
第三行"""
    print(m.lines().len(), "[" + m.slice(1, 4) + "]")
    return 0
```

```text
换行:
下一行
引号 " 反斜杠 \ 单引号 '
A 你 😀
10 9 7 8 12 13 0
4 [第]
```

三引号 `"""` 是多行字符串，规则很朴素：**里面的东西原样保留**。

- 开头的换行也算内容（上面 `m` 的第一个字符是换行，所以 `lines()` 是 4 段而不是 3 段）。
- **缩进不会被剥掉**（第 2 段真的带着 4 个空格）。想要干净的文本就别缩进，或者自己 `trim()`。
- `m.slice(1, 4)` 取到的是「第」的 3 个字节 —— `slice` 也按字节算，
  按字符切要用 `slice_chars`（[6.5](#65-按码点处理中文)）。

`char` 装不下多字节字符，编译器会直接告诉你怎么办：

```fa
fn main() -> i64:
    print('\u4F60')     # ❌ char 只有一个字节
    return 0
```

```text
语法错误 (行 2, 列 11): char 是单字节（u8），装不下 U+4F60；
多字节字符请写成字符串 "\u4F60"
```

### 6.3 插值

`{}` 里可以放**任意表达式**：变量、算术、下标、方法调用、条件表达式，
甚至带引号的字面量和嵌套的花括号：

```fa
fn main() -> i64:
    let name = "世界"
    let n = 42
    let v = Vec<i64>[1, 2, 3]
    let m = Map<str, i64>["a": 1]
    print("你好, {name}! n={n}, n*2={n * 2}")
    print("下标 {v[1]}, 方法 {name.char_len()}, 容器 {v} {m}")
    print("内层引号 {m["a"]}, 条件 {if n > 10 { "大" } else { "小" }}")
    print("{{n}} 是字面花括号包住值; 空花括号: {chr(123)}{chr(125)}")
    return 0
```

```text
你好, 世界! n=42, n*2=84
下标 2, 方法 2, 容器 [1, 2, 3] {"a": 1}
内层引号 1, 条件 大
{42} 是字面花括号包住值; 空花括号: {}
```

插值的值就是 `print` 出来的那个形式（`str(x)`），所以容器、结构体、枚举都能直接塞进去。

关于花括号，有三条容易踩的规则：

- **`{{expr}}` 的结果是 `{值}`**：`{{` 让第一个花括号变成字面字符，第二个才开始插值；
  结尾同理。所以它**不是**「转义成一对字面花括号」。
- **`\{` 挡不住插值。**插值是在字符串**值**上做二次切分的，`\{n\}` 先被转义成 `{n}`，
  然后照样被当成插值算掉。真要打印字面花括号，用 `chr(123)` / `chr(125)` 或者拼接。
- **`{}` 空着是编译错误**（不是打印两个花括号）：

```fa
fn main() -> i64:
    print("{}")         # ❌ 空插值
    return 0
```

```text
语法错误 (行 2, 列 11): 字符串插值 {} 里是空的：花括号里要放表达式（如 "{n}"）；
要打印字面花括号请用 chr(123) / chr(125) 或字符串拼接
```

字符串**不会**自动和别的类型相加，插值才是拼接的正道：

```fa
fn main() -> i64:
    print("a" + 1)      # ❌ 字符串不能和整数相加
    return 0
```

```text
类型错误 (行 2, 列 11): 运算符 '+' 不支持 str 与 i64
```

要手动转就用 `str(x)` 或 `x.to_str()`（两者等价，任何类型都有 `to_str()`）。
顺带一提：数字字面量后面直接跟方法也是可以的 —— `42.to_str()` 是 `"42"`。

### 6.4 方法全表

`str` 上一共 28 个方法。按用途分组记，比按字母序背容易。

**长度与取值**

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.len()` / `len(s)` | i64 | **字节**数 |
| `s.bytes()` | i64 | `len()` 的历史别名（**不是**字节数组） |
| `s[i]` / `s.at(i)` | char / i64 | 第 i 个**字节**；越界 panic |
| `s.chars()` | Vec\<char\> | 拆成字节数组（`char` 就是 u8） |
| `s.cstr()` | *u8 | C 字符串指针（不加引用，给 extern 用） |

**查找与判断**

```fa
fn main() -> i64:
    let s = "  Hello, FA  "
    let t = s.trim()
    print("[" + s.trim() + "]", "[" + s.trim_start() + "]", "[" + s.trim_end() + "]")
    print(s.len(), s.bytes(), s.at(2), s.at(0) as i64)
    print(t.find("FA"), t.find("zz"), t.contains("Hello"), t.count("l"))
    print(t.starts_with("He"), t.ends_with("FA"), "ab".starts_with("abc"))
    return 0
```

```text
[Hello, FA] [Hello, FA  ] [  Hello, FA]
13 13 72 32
7 -1 true 2
true true false
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.find(sub)` | i64 | 第一次出现的位置，找不到是 **-1** |
| `s.contains(sub)` | bool | 是否包含（就是 `find(...) >= 0`） |
| `s.count(sub)` | i64 | 出现次数（不重叠） |
| `s.starts_with(p)` / `s.ends_with(p)` | bool | 前缀 / 后缀 |
| `s.eq(t)` | bool | 内容相等（一般直接写 `s == t`） |
| `s.trim()` / `s.trim_start()` / `s.trim_end()` | str | 去首尾 / 只去首 / 只去尾空白 |

`s.at(2)` 给的是 72（`'H'` 的字节值）—— `at` 的返回类型标成 i64，
要当字符用就 `chr(...)` 一下；`s[2]` 下标写法给的是 `char`，打印出来是 `H`。

**切片、替换、大小写**

```fa
fn main() -> i64:
    let t = "  Hello, FA  ".trim()
    print("[" + t.slice(0, 5) + "]", "[" + t.slice(7, -1) + "]", "[" + t.slice(6, 9) + "]")
    print(t.upper(), t.lower())
    print(t.replace("l", "L"), "[" + "aaa".replace("a", "") + "]", t.replace("zz", "Q"))
    return 0
```

```text
[Hello] [] [ FA]
HELLO, FA hello, fa
HeLLo, FA [] Hello, FA
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.slice(a, b)` | str | 取 `[a, b)`，**字节**下标 |
| `s.replace(旧, 新)` | str | 替换**全部**；找不到就原样返回 |
| `s.upper()` / `s.lower()` | str | 只对 ASCII 生效 |
| `s.repeat(n)` | str | 重复 n 次（`n` 为 0 得空串） |

`slice` 的两个坑：**必须给两个参数**（`s.slice(1)` 是编译错误），
而且**负数不是「从末尾数」**——`t.slice(7, -1)` 因为 7 > -1 直接得到空串。
要「去掉最后 k 个字节」得自己算：`s.slice(0, s.len() - k)`。
切多字节字符的中间不会报错，只会切出半个字符（乱码）；按字符切用 `slice_chars`。

**切分与拼接**

```fa
fn main() -> i64:
    let parts = "a,b,,c".split(",")
    print(parts, parts.len(), parts.join("|"))
    print("line1\nline2\n\nline4".lines())
    print("x1y2".lines(), "a\n".lines())
    return 0
```

```text
["a", "b", "", "c"] 4 a|b||c
["line1", "line2", "", "line4"]
["x1y2"] ["a", ""]
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.split(sep)` | Vec\<str\> | 按分隔符切；**空字段会保留**（`"a,,b"` → 3 段） |
| `s.lines()` | Vec\<str\> | 按换行切，自动去掉行尾的 `\r`；尾部换行会多出一个空段 |
| `s.join(...)` | — | **str 没有 join**；join 是 `Vec<str>` 的方法 |

**转换**

```fa
fn main() -> i64:
    print("42".to_i64(), "3.5".to_f64(), "  7 ".to_i64(), "12x".to_f64())
    print("abc".to_i64(), "".to_i64(), "abc".to_f64())
    print("ab".repeat(3), "abc".chars(), "abc".chars()[2] as i64)
    print(str(42), 3.5.to_str(), 42.to_str())
    return 0
```

```text
42 3.5 7 12.0
0 0 0.0
ababab ['a', 'b', 'c'] 99
42 3.5 42
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.to_i64()` / `s.to_f64()` | i64 / f64 | 解析数字；**失败返回 0**，不报错也不抛异常 |
| `x.to_str()` / `str(x)` | str | 任何值转文本（与 `print` 的形式一致） |

`s.to_i64()` 会先吃掉首尾空白（`"  7 "` → 7），遇到非法字符就停下（`"12x"` → 12）。
**没法区分「真的是 0」和「解析失败」**——需要严格校验就自己先看 `find` / 逐字符判断，
或者用 `try` 风格的写法：`if s.to_i64() == 0 and s != "0" { 处理失败 }`。

### 6.5 按码点处理中文

`char` 是一个字节，所以「第 i 个字符」这件事在 UTF-8 里得单独一套方法：

```fa
fn main() -> i64:
    let u = "你好世界"
    print(u.len(), u.char_len())
    print(u.char_at(0), u.char_at(3), chr(u.char_at(1)))
    print(u.slice_chars(0, 2), "[" + u.slice_chars(1, 3) + "]")
    let cps = u.codepoints()
    print(cps, cps.len())
    let mixed = "a你b"
    print(mixed.len(), mixed.char_len(), mixed.codepoints())
    for i in 0..u.char_len() {
        print(i, chr(u.char_at(i)))
    }
    return 0
```

```text
12 4
20320 30028 好
你好 [好世]
[20320, 22909, 19990, 30028] 4
5 3 [97, 20320, 98]
0 你
1 好
2 世
3 界
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `s.char_len()` | i64 | **码点**个数（`"你好世界"` 是 4，`len()` 是 12） |
| `s.char_at(i)` | i64 | 第 i 个码点；越界报错退出 |
| `s.codepoints()` | Vec\<i64\> | 全部码点 |
| `s.slice_chars(a, b)` | str | 按码点切 `[a, b)`，下标自动夹紧，不会切坏字符 |

要点：

- `char_at` 返回 **i64 码点**，不是 `char`（`char` 装不下 20320）。要打印成字就得
  `chr(u.char_at(i))`。
- `slice_chars(8, 100)` 这种超界不会报错，会夹到实际长度 —— 和 `slice` 的行为不同。
- 非法 / 截断的 UTF-8 按单字节码点兜底，不会读到缓冲区外面。
- 往返是精确的：`for cp in s.codepoints() { out = out + chr(cp) }` 得到的 `out == s`。

### 6.6 拼接的性能

字符串不可变，所以 `s = s + x` **每次都重新分配并整串复制**。在循环里这么写是 O(n²)：

```fa
fn main() -> i64:
    let bad = ""
    for i in 0..20000 {
        bad = bad + "x"
    }
    let parts = Vec<str>[]
    for i in 0..20000 {
        parts.push("x")
    }
    let good = parts.join("")
    print(bad.len(), good.len(), bad == good)
    return 0
```

```text
20000 20000 true
```

两种写法结果一样，代价差很多：前者复制了约 2 亿字节，后者只分配一次。
**规则**：循环里要拼字符串，先 `Vec<str>` 收集，最后一次 `join(sep)`。
插值同理（`"{a}{b}"` 在循环里也是每轮新建），少量拼接不用管，几万次以上就要改。

顺带说清楚：这么写**不会内存泄漏**。引用计数在每次覆盖 `bad` 时释放旧值，
20000 轮的循环 RSS 是平的（整套用例在 AddressSanitizer 下跑过，见 README §5）。

### 6.7 这一节的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `"你好".len()` 是 6 | `len()` 数字节 | 用 `char_len()` |
| `s[1]` 打出来是乱码 | 取到了多字节字符的中间一字节 | 用 `char_at(i)` + `chr(...)` |
| `s.slice(1)` 编译错误 | `slice` 必须两个参数 | `s.slice(1, s.len())` |
| `s.slice(2, -1)` 是空串 | 负数不是「从末尾数」 | `s.slice(2, s.len() - 1)` |
| `"a" + 1` 编译错误 | 字符串不自动和其它类型相加 | `"{a}"` 插值，或 `+ str(1)` |
| `42.to_str()` 能用但 `42.` 不行 | 小数点后必须是数字才算浮点 | 想写浮点就 `42.0` |
| `print("{}")` 编译错误 | 空插值 | 要字面花括号用 `chr(123)` / `chr(125)` |
| `"{{n}}"` 打出 `{5}` | `{{` 只让**一个**花括号变字面 | 见 [6.3](#63-插值) |
| `s.bytes()` 不是字节数组 | 它是 `len()` 的别名 | 字节用 `chars()`，码点用 `codepoints()` |
| `"abc".to_i64()` 是 0 | 解析失败返回 0，不报错 | 需要严格校验就自己检查字符 |
| `s[0] = "x"` 编译错误 | str 不可变 | 用 `Vec<char>`，或 `replace` |
| 循环里 `s = s + x` 很慢 | 每轮整串复制，O(n²) | `Vec<str>` + `join` |

## 7. 控制流

FA 的块有两种等价写法：**冒号 + 缩进**（Python 味）和**花括号**（C 味），
两种都收，同一个块里别混着写。这一节每段代码后面的输出，都是把程序真跑一遍贴上去的。

先给一张地图，后面逐个展开：

| 想干什么 | 写法 |
|---|---|
| 分支 | `if` / `elif` / `else`，也能当表达式用 |
| 条件循环 | `while 条件:` |
| 遍历 | `for x in 可遍历对象:`（range / Vec / Map / str / 数组） |
| 计数循环 | `for (let i = 0; i < n; i += 1) { ... }` |
| 无限循环 | `loop:` 配 `break` |
| 多路分支 | `match`（字面量、枚举变体、`_` 兜底），也能当表达式用 |
| 收尾动作 | `defer 表达式`（块结束时跑，后进先出） |

### 7.1 if / elif / else

```fa
fn classify(n: i64) -> str:
    if n < 0:
        return "负"
    elif n == 0:
        return "零"
    else:
        return "正"

fn classify2(n: i64) -> str:
    if n < 0 { return "负" } else if n == 0 { return "零" } else { return "正" }

fn main() -> i64:
    print(classify(-3), classify(0), classify(7))
    print(classify2(-3), classify2(0), classify2(7))
    let a = if 3 > 2 { "大" } else { "小" }
    let b = if a == "大" { 10 } elif a == "中" { 5 } else { 0 }
    print(a, b)
    let mut n = 1
    if n > 0: n = 100
    print(n)
    return 0
```

```text
负 零 正
负 零 正
大 10
100
```

这段里已经出现了四种用法：缩进式分支链、花括号式分支链、`if` 当表达式、
`if 条件: 单句`。下面四件事值得单独说清楚。

**一、条件不用括号，但只能是 bool 或整数。** 整数按 C 的习惯解释：0 是假，
非 0（包括负数）是真。

```fa
fn main() -> i64:
    let vals = Vec<i64>[0, 1, -1, 42]
    for n in vals {
        if n { print(n, "-> 真") } else { print(n, "-> 假") }
    }
    return 0
```

```text
0 -> 假
1 -> 真
-1 -> 真
42 -> 真
```

字符串、Vec、Map、f64 **不能**当条件 —— 没有 Python 那种「空串 / 空表为假」的规则：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let s = ""
    if s { print("空串算假") }
    return 0
```

```text
类型错误 (行 4, 列 5): if 条件必须是 bool（或整数）
        if s { print("空串算假") }
        ^
```

要判空就写明白：`if s.len() == 0 { ... }`、`if v.len() > 0 { ... }`、`if f > 0.0 { ... }`。

**二、花括号写法的 `else` / `elif` 必须和右花括号同一行**（和 C / Go 一样）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn classify(n: i64) -> str:
    if n < 0 { return "负" }
    else { return "非负" }
```

```text
语法错误 (行 4, 列 5): 'else' 接不上前面的 if：花括号写法要和右花括号同一行（写成 `} else ...`），缩进写法要紧跟在 if 块的下一行、和 if 同缩进
        else { return "非负" }
        ^
```

同一行里 `} else {`、`} elif 条件 {`、`} else if 条件 {` 三种都收；
缩进写法则 `elif` 和 `else if` 都收。多行花括号也一样，只是右花括号和 else 挨着：

```fa
fn sign(n: i64) -> str:
    if n < 0 {
        return "负"
    } else if n == 0 {
        return "零"
    } else {
        return "正"
    }

fn main() -> i64:
    print(sign(-3), sign(0), sign(7))
    return 0
```

```text
负 零 正
```

**三、`if` 当表达式用时必须有 `else`**，否则可能没有值：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let x = if 1 > 0 { 5 }
    print(x)
    return 0
```

```text
类型错误 (行 3, 列 13): 作为表达式的 if 必须有 else 分支（否则可能没有值）
        let x = if 1 > 0 { 5 }
                ^
```

**四、各分支的类型必须一致**（`if` 表达式的结果要有一个确定的类型）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let s = if 1 > 0 { "y" } else { 42 }
    print(s)
    return 0
```

```text
类型错误 (行 3, 列 13): 作为表达式的 if，各分支类型不一致：str 与 i64
        let s = if 1 > 0 { "y" } else { 42 }
                ^
```

`elif` 链当表达式用也一样，最后必须落到 `else`（见本节第一个例子里的 `b`）。

### 7.2 while

```fa
fn main() -> i64:
    let mut i = 0
    while i < 3:
        print("i =", i)
        i += 1

    let mut n = 0
    while true {
        n += 1
        if n >= 3 { break }
    }
    print("n =", n)
    return 0
```

```text
i = 0
i = 1
i = 2
n = 3
```

条件的规则和 `if` 完全一样（bool 或整数）。`while true` 配 `break` 是常见写法，
中途 `return` 也一样能出去 —— 出去之前该跑的 `defer` 会跑（见 [7.7](#77-defer)）。
循环变量记得用 `let mut`，否则 `i += 1` 会报「不能给不可变变量赋值」。

### 7.3 for：遍历与计数两种形态

**形态一：`for x in 可遍历对象`。** 五种东西可以直接遍历：

```fa
fn main() -> i64:
    for i in 0..3:
        print("range:", i)

    let v = Vec<i64>[10, 20]
    for x in v {
        print("vec:", x)
    }

    let m = Map<str, i64>()
    m.set("b", 2)
    m.set("a", 1)
    for k in m {
        print("map:", k, m[k])
    }

    for c in "ab" {
        print("str:", c, chr(c))
    }

    let arr = [1, 2]
    for x in arr {
        print("arr:", x)
    }
    return 0
```

```text
range: 0
range: 1
range: 2
vec: 10
vec: 20
map: b 2
map: a 1
str: a a
str: b b
arr: 1
arr: 2
```

| 遍历对象 | 循环变量拿到什么 | 顺序 |
|---|---|---|
| `a..b` / `a..=b` | i64 | 递增；`..` 不含 b，`..=` 含 b |
| `Vec<T>` | 元素的值（一份拷贝） | 下标 0 到最后 |
| `Map<K, V>` | **键** | 插入顺序 |
| `str` | `char`（单字节） | 从左到右按字节 |
| `[T; N]` 数组 | 元素的值 | 下标 0 到最后 |

三点补充：

- 遍历字符串拿到的是 **char（一个字节）**。中文这类多字节文本要用
  `for cp in s.codepoints()`（见 [6.5](#65-按码点处理中文)），否则一个汉字会被拆成三片。
- 遍历 Map 只给键，值用 `m[k]` 或 `m.get(k)` 取；只要键或只要值也有现成方法：

```fa
fn main() -> i64:
    let m = Map<str, i64>()
    m.set("b", 2)
    m.set("a", 1)
    print("keys:", m.keys().to_str(), "values:", m.values().to_str())
    let v = Vec<i64>[10, 20]
    let mut idx = 0
    for x in v {
        print("下标:", idx, x)
        idx += 1
    }
    return 0
```

```text
keys: ["b", "a"] values: [2, 1]
下标: 0 10
下标: 1 20
```

- **没有 `for k, v in m` 这种解构写法**，也没有 `enumerate()`。要下标就自己数
  （上面 `idx` 那样），或者用计数 for。写成两个变量是语法错误：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let m = Map<str, i64>()
    m.set("a", 1)
    for k, v in m:
        print(k, v)
    return 0
```

```text
语法错误 (行 5, 列 10): 期望 'in'，实际得到 ','
        for k, v in m:
             ^
```

**range 只有 `起..止` 和 `起..=止` 两种，没有步进**（`0..10..2` 这种不认）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    for i in 0..10..2 {
        print(i)
    }
    return 0
```

```text
类型错误 (行 3, 列 14): 范围运算符不能连用：FA 的 range 只有 `起..止` / `起..=止`，没有步进写法。要跳着走请用 while，或 `for i in 0..n { let j = i * 2 }`
        for i in 0..10..2 {
                 ^
```

起止写反了不是错误，是**一次都不循环**（空区间）：

```fa
fn main() -> i64:
    let mut t = 0
    for i in 5..0 { t += 1 }
    print("5..0 循环了", t, "次")
    for i in 3..3 { t += 1 }
    print("3..3 之后 t =", t)
    for i in 0..=3 { t += 1 }
    print("0..=3 循环了", t, "次")
    return 0
```

```text
5..0 循环了 0 次
3..3 之后 t = 0
0..=3 循环了 4 次
```

**形态二：C 风格计数 for。** 三段式要写在**括号里**，块用花括号或冒号缩进都行：

```fa
fn main() -> i64:
    for (let i = 0; i < 3; i += 1) {
        print("花括号:", i)
    }
    for (let j = 0; j < 3; j += 1):
        print("缩进:", j)
    let mut k = 5
    for (; k > 3; k -= 1) {
        print("省掉初始化:", k)
    }
    return 0
```

```text
花括号: 0
花括号: 1
花括号: 2
缩进: 0
缩进: 1
缩进: 2
省掉初始化: 5
省掉初始化: 4
```

初始化段里的 `let i` 是循环自己的变量，出了循环就不存在；三段里的后两段
（条件、步进）都能省，`for (;;) { ... }` 就是死循环 —— 不过这种场合写 `loop:`
更清楚。不带括号、想学 Go 写 `for i := 0; ...` 是不行的：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    for i := 0; i < 3; i += 1 {
        print(i)
    }
    return 0
```

```text
语法错误 (行 3, 列 11): 期望 'in'，实际得到 ':'
        for i := 0; i < 3; i += 1 {
              ^
```

### 7.4 loop：无限循环

`loop:` 就是「条件永远为真」的循环，只能靠 `break`（或 `return`）出去：

```fa
fn main() -> i64:
    let mut n = 0
    loop:
        n += 1
        if n >= 3 { break }
    print("loop 出来时 n =", n)

    let mut i = 0
    loop {
        i += 1
        if i > 2 {
            break
        }
    }
    print("花括号 loop 出来时 i =", i)
    return 0
```

```text
loop 出来时 n = 3
花括号 loop 出来时 i = 3
```

读输入读到尽头、重试到成功为止、状态机 —— 这类「不知道要转几圈」的循环用
`loop:` 比 `while true` 意图更明确。

### 7.5 break 与 continue

`break` 跳出**当前这一层**循环，`continue` 直接进入下一轮：

```fa
fn main() -> i64:
    let mut total = 0
    for i in 0..6 {
        if i == 2 { continue }
        if i == 4 { break }
        total += i
    }
    print("total =", total)

    for i in 0..2 {
        for j in 0..3 {
            if j == 1 { break }
            print("内层:", i, j)
        }
    }
    return 0
```

```text
total = 4
内层: 0 0
内层: 1 0
```

`total = 4` 是 `0 + 1 + 3`：2 被 `continue` 跳过，4 触发 `break`，5 根本没轮到。
嵌套时 `break` 只结束**最里面**那一层，外层接着转（所以 `内层: 1 0` 还在）。

要点：

- `break` / `continue` 只能出现在循环里，写在外面是编译错误：
  `类型错误 (行 3, 列 5): break/continue 只能出现在循环内`。
- FA 没有带标签的 `break outer`。要一次跳两层，用一个标志变量，或者把内层循环
  抽成函数用 `return`。
- 这两种跳转都会**先把该跑的收尾跑完**：`defer` 会执行，块里的引用计数会释放，
  不会泄漏（细节见 [7.7](#77-defer) 和 [15](#15-内存是怎么管的)）。
- `continue` 在五种遍历对象上都正常（range / Vec / Map / str / 数组），
  在 `while`、计数 for、`loop:` 里也正常。

### 7.6 match：多路分支

`match` 是 `if/elif` 链的替代品：拿一个值和一组**模式**逐个比，命中哪个就走哪个分支。
同样有三种写法，下面是同一段逻辑的三种样子：

```fa
fn main() -> i64:
    let n = 2
    match n:
        1:
            print("一")
        2:
            print("二")
        _:
            print("其它")
    let s = match n { 1: "一" 2: "二" _: "其它" }
    print("表达式形式:", s)
    match n {
        1: print("花括号多行 一")
        2: print("花括号多行 二")
        _: print("花括号多行 其它")
    }
    return 0
```

```text
二
表达式形式: 二
花括号多行 二
```

写法上的三个细节：

- 花括号形式里，分支之间**不用逗号也不用分号**，空白就够分隔；
- 缩进形式里，分支体可以是一句（同一行）或多句（下一行缩进）；
- `match` 当表达式用时，**必须有 `_` 兜底**（或覆盖枚举的全部变体），
  各分支的类型也要一致 —— 规则和 `if` 表达式一样。

**模式能写什么。** 字面量（i64 / f64 / str / bool）、枚举变体、以及万能的 `_`：

```fa
fn main() -> i64:
    let s = "b"
    match s:
        "a": print(1)
        "b": print(2)
        _: print(0)
    let x = 2.5
    match x:
        2.5: print("2.5")
        _: print("其它浮点")
    let ok = true
    match ok:
        true: print("真")
        false: print("假")
    let label = match s { "a": "甲" "b": "乙" _: "其它" }
    print("表达式形式:", label)
    return 0
```

```text
2
2.5
真
表达式形式: 乙
```

枚举变体可以**把载荷绑定到名字上**，也可以只认变体不看载荷：

```fa
enum Color:
    Red
    Green(i64)
    Blue(str)

fn name(c: Color) -> str:
    match c:
        Color.Red:
            return "红"
        Color.Green(n):
            return "绿({n})"
        Color.Blue(s):
            return "蓝({s})"
    return "?"

fn main() -> i64:
    print(name(Color.Red), name(Color.Green(5)), name(Color.Blue("天")))
    # 不绑定载荷，只认变体
    let c = Color.Green(5)
    match c {
        Color.Red: print("红")
        Color.Green: print("绿（不看载荷）")
        _: print("其它")
    }
    # 漏掉分支会怎样：悄悄掉过去
    let d = Color.Blue("海")
    match d:
        Color.Red:
            print("红")
    print("match 之后照常执行")
    return 0
```

```text
红 绿(5) 蓝(天)
绿（不看载荷）
match 之后照常执行
```

**match 不做穷尽性检查**：没有分支命中、又没写 `_`，程序就继续往下走，
不报错也不 panic（上面 `Color.Blue("海")` 那次什么都没打印）。这在函数里最容易埋雷：

```fa
enum Color:
    Red
    Green(i64)

fn name(c: Color) -> str:
    match c:
        Color.Red:
            return "红"

fn main() -> i64:
    print("[" + name(Color.Red) + "]")
    print("[" + name(Color.Green(2)) + "]")
    return 0
```

```text
[红]
[]
```

`name(Color.Green(2))` 一个分支都没命中，函数就这么走到末尾 —— 编译器在结尾补一个
**零值**返回（str 是空串，i64 是 0，Vec 是空表，见 [8.4](#84-返回值)）。
不崩，但多半不是你想要的。**习惯**：`match` 永远带上 `_`，或者把所有变体列全。
反过来，只要每个分支都 `return`、变体也列全了，函数末尾就**不用**再补 `return`：

```fa
enum Color:
    Red
    Green(i64)

fn name(c: Color) -> str:
    match c:
        Color.Red:
            return "红"
        Color.Green(n):
            return "绿({n})"

fn main() -> i64:
    print(name(Color.Red), name(Color.Green(2)))
    let n = 1
    match n:
        1:
            print("分支里第一句")
            print("分支里第二句")
        _:
            print("其它")
    return 0
```

```text
红 绿(2)
分支里第一句
分支里第二句
```

**不支持的两种模式**（写出来是编译错误，不是静默忽略）。一是 Rust 那种守卫：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let n = 5
    match n:
        x if x > 3: print("大")
        _: print("小")
    return 0
```

```text
类型错误 (行 5, 列 9): 未定义的标识符 'x'
            x if x > 3: print("大")
            ^
```

二是「一个分支匹配多个值」：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let n = 5
    match n:
        1: print("一")
        2, 3: print("二或三")
        _: print("其它")
    return 0
```

```text
语法错误 (行 6, 列 10): 无法解析的表达式起始 token ','
            2, 3: print("二或三")
             ^
```

这两种需求的替代写法：守卫改成 `elif` 链，或者在分支体里再套一层 `if`；
多模式就把分支写两遍，共用一个函数：

```fa
fn small(n: i64) -> str:
    return "小"

fn main() -> i64:
    let n = 3
    match n:
        1: print(small(n))
        2: print(small(n))
        3: print(small(n))
        _: print("其它")
    # 或者干脆用 if/elif，条件想怎么写就怎么写
    if n == 2 or n == 3 { print("二或三") }
    return 0
```

```text
小
二或三
```

### 7.7 defer

`defer` 后面跟一个表达式，它会在**当前块结束时**执行；同一个块里写了好几个，
按**后进先出**的顺序跑：

```fa
fn one():
    defer print("先注册的后跑")
    defer print("后注册的先跑")
    print("函数体")

fn main() -> i64:
    one()
    for i in 0..2 {
        defer print("  轮次收尾", i)
        print("轮次开始", i)
    }
    for i in 0..5 {
        defer print("  break 也跑 defer", i)
        if i == 1 { break }
    }
    return 0
```

```text
函数体
后注册的先跑
先注册的后跑
轮次开始 0
  轮次收尾 0
轮次开始 1
  轮次收尾 1
  break 也跑 defer 0
  break 也跑 defer 1
```

**defer 是块作用域，不是函数作用域** —— 这是最容易记错的一点。写在循环体里，
就是**每一轮**结束时跑一次（上面 `轮次收尾 0` / `轮次收尾 1`）；想整个函数结束时
才跑一次，就写在函数体那一层。

**defer 里的值是执行时的值，不是注册时的值**（晚绑定）：

```fa
fn main() -> i64:
    let mut x = 1
    defer print("defer 看到的 x =", x)
    x = 2
    print("主体结束时 x =", x)

    let s = "旧"
    defer print("defer 看到的 s =", s)
    s = "新"

    let v = Vec<i64>[1]
    defer print("defer 看到的 v =", v.to_str())
    v.push(2)
    return 0
```

```text
主体结束时 x = 2
defer 看到的 v = [1, 2]
defer 看到的 s = 新
defer 看到的 x = 2
```

三个 defer 都在块结束时才读变量，所以看到的是改过之后的 `2` / `"新"` / `[1, 2]`；
输出顺序则是注册的倒序（v、s、x）。

**离开块的每条路径都会跑 defer**：正常走完、`return`、`break`、`continue`，
甚至「一个 return 都没命中、掉到函数末尾」也算：

```fa
fn f() -> i64:
    defer print("defer 跑了")
    if false { return 1 }

fn main() -> i64:
    print("返回", f())
    return 0
```

```text
defer 跑了
返回 0
```

（`f()` 掉到末尾，返回值是 i64 的零值 0；defer 照样跑，局部引用照样释放，
见 [8.4](#84-返回值)。）

**`defer` 后面只能跟一个表达式**，不能跟一个块：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    defer {
        print("第一句")
        print("第二句")
    }
    return 0
```

```text
语法错误 (行 3, 列 11): 无法解析的表达式起始 token '{'
        defer {
              ^
```

要收尾的事情有好几件，就写成一个函数再 `defer cleanup()`，或者注册多个 defer
（倒着跑，正好适合「后开的先关」）。

典型用途：`defer f.close()`、`defer print("[结束]")` 这类成对动作 ——
注册在使用资源的语句旁边，读者一眼能看出「这东西会被收掉」，也不用在每条
`return` 前面重复一遍。FA 的字符串、Vec、Map 是引用计数自动回收的，
不需要 defer 来释放；defer 是给**你自己**的资源（文件、锁、C 那边 malloc 的内存、
临时日志）用的。手动 `new` 出来的指针要 `free(p)`，见 [14](#14-指针与-new)。

### 7.8 这一节的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `if s { }`（s 是 str）编译错误 | 条件只能是 bool 或整数 | `if s.len() == 0 { }` |
| `if v { }`（v 是 Vec）编译错误 | 没有「空表为假」的规则 | `if v.len() > 0 { }` |
| `if f { }`（f 是 f64）编译错误 | 浮点不当条件 | `if f > 0.0 { }` |
| `if n { }` 里 n 是 i64 | 0 假、非 0 真（负数也是真） | 想要严格就写 `n != 0` |
| `}` 之后另起一行写 `else` 报错 | 花括号写法要和 `}` 同一行 | `} else { ... }` |
| `let x = if c { 1 }` 报错 | if 当表达式必须有 else | 补上 else |
| if 表达式两个分支类型不同报错 | 结果要有一个确定类型 | 统一类型，或 `str(n)` |
| `for k, v in m` 报错 | 没有解构写法 | `for k in m` + `m[k]` |
| `for i := 0; ...` 报错 | 计数 for 要括号和 let | `for (let i = 0; i < n; i += 1) {` |
| `0..10..2` 报错 | range 没有步进 | `while`，或循环体里 `let j = i * 2` |
| `for i in 5..0` 一次都不循环 | 起止反了就是空区间 | `for (let i = 5; i > 0; i -= 1)` |
| 遍历字符串拿到单字节 | 循环变量是 `char` | 中文用 `s.codepoints()` |
| 遍历 Map 只拿到键 | 设计如此 | `m[k]` / `keys()` / `values()` |
| match 漏了分支不报错也不 panic | 不做穷尽检查，直接掉过去 | 永远带 `_`，或把变体列全 |
| 函数没命中 return 也能编译 | 结尾补零值（str 空串、i64 0、Vec 空表） | 想拦住就自己 `assert` |
| `x if x > 3:` 守卫报错 | 不支持守卫 | 分支体里再套 `if`，或用 `elif` 链 |
| `2, 3:` 多模式报错 | 不支持一个分支匹配多个值 | 写两遍，或改成 `if a == 2 or a == 3` |
| match 当表达式缺 `_` 报错 | 否则可能没有值 | 补 `_`，或把枚举变体列全 |
| `defer { 多句 }` 报错 | defer 只接一个表达式 | 包成一个函数，或注册多个 defer |
| 循环里的 defer 每轮都跑 | defer 是**块**作用域 | 想函数末尾跑就写在函数体那层 |
| defer 里的值是「后来」的值 | 执行时才读变量（晚绑定） | 想固定当刻的值就先存进一个 `let` |
| `break` 只跳出一层 | 没有带标签的 break | 标志变量，或把内层抽成函数用 `return` |
| `break` 写在循环外报错 | 只能在循环里 | 检查缩进层级 |
| `print("x =", f())` 里 f() 的输出排在前面 | 实参先全部求值，再输出 | 想控制顺序就分成两句 print |

## 8. 函数

### 8.1 定义与调用

一个函数就是 `fn` + 名字 + 参数表 + （可选的）返回类型 + 一个块：

```fa
fn add(a: i64, b: i64) -> i64:
    return a + b

fn greet(name: str):
    print("你好,", name)

fn main() -> i64:
    print(add(1, 2))
    greet("世界")
    return 0
```

```text
3
你好, 世界
```

几条基本规则：

- **参数必须写类型**；返回类型不写就是「没有返回值」，块里可以写光秃秃的
  `return`，也可以一路走完。
- 函数体两种写法都行：冒号 + 缩进，或者花括号。
- **定义顺序无关**：可以先调用后定义，两个函数也可以互相递归调用。
- **没有重载**：同一个名字定义两次是编译错误（`'later' 重复定义（第一次在第 5 行）`）。
- 实参个数、类型对不上，编译期就拦下来，不会拖到运行时：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn add(a: i64, b: i64) -> i64:
    return a + b

fn main() -> i64:
    print(add(1))
    return 0
```

```text
类型错误 (行 6, 列 14): 函数需要 2 个实参，实际传入 1 个
        print(add(1))
                 ^
```

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn add(a: i64, b: i64) -> i64:
    return a + b

fn main() -> i64:
    print(add(1, "x"))
    return 0
```

```text
类型错误 (行 6, 列 14): 第 2 个实参: 类型不匹配，期望 i64，实际 str
        print(add(1, "x"))
                 ^
```

**三样不支持的东西**，以及替代写法。一是多重返回值（没有元组）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn two() -> (i64, str):
    return (1, "a")

fn main() -> i64:
    return 0
```

```text
语法错误 (行 2, 列 13): 期望 'NAME'，实际得到 '('
    fn two() -> (i64, str):
                ^
```

要一次返回几个值，就定义一个结构体装起来：

```fa
struct Div:
    q: i64
    r: i64

fn divmod(a: i64, b: i64) -> Div:
    return Div{q: a / b, r: a % b}

fn main() -> i64:
    let d = divmod(17, 5)
    print(d.q, d.r)
    return 0
```

```text
3 2
```

二是默认参数值：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn f(n: i64 = 1) -> i64:
    return n

fn main() -> i64:
    print(f())
    return 0
```

```text
语法错误 (行 2, 列 13): 期望 ')'，实际得到 '='
    fn f(n: i64 = 1) -> i64:
                ^
```

三是具名实参（`f(x = 3)` 同样报 `期望 ')'，实际得到 '='`）。
想要「可选参数」的效果，就写两个函数：`fn f(n: i64) -> i64` 和
`fn f_default() -> i64: return f(1)`。

### 8.2 参数是怎么传的

**参数在函数体内可以直接改**（不用 `mut`），改的是自己那一份；
调用方的变量不受影响：

```fa
fn bump(n: i64) -> i64:
    n = n + 1
    return n

fn main() -> i64:
    let x = 1
    print(bump(x), "外面还是", x)
    return 0
```

```text
2 外面还是 1
```

但「自己那一份」对不同类型含义不一样 —— 这是 FA 里最容易踩的一条：

```fa
struct P:
    x: i64
    y: i64

fn touch_vec(v: Vec<i64>):
    v.push(99)

fn touch_map(m: Map<str, i64>):
    m.set("新", 1)

fn touch_str(s: str):
    s = s + "改了"
    print("  函数内 s =", s)

fn touch_struct(p: P):
    p.x = 100

fn touch_arr(a: [i64; 2]):
    a[0] = 77

fn main() -> i64:
    let v = Vec<i64>[1]
    touch_vec(v)
    print("Vec:", v.to_str())

    let m = Map<str, i64>()
    touch_map(m)
    print("Map:", m.to_str())

    let s = "原值"
    touch_str(s)
    print("str:", s)

    let p = P{x: 1, y: 2}
    touch_struct(p)
    print("struct:", p.x, p.y)

    let a = [1, 2]
    touch_arr(a)
    print("arr:", a[0], a[1])
    return 0
```

```text
Vec: [1, 99]
Map: {"新": 1}
  函数内 s = 原值改了
str: 原值
struct: 1 2
arr: 1 2
```

| 参数类型 | 函数里改了，外面看得见吗 | 为什么 |
|---|---|---|
| i64 / f64 / bool / char / 指针 | 看不见 | 传的是值的拷贝 |
| `str` | 看不见 | 不可变；`s = s + "x"` 只是让参数指向新串 |
| `struct` / `[T; N]` 数组 | 看不见 | 整个拷贝一份进去 |
| `Vec<T>` / `Map<K, V>` | **看得见** | 引用计数，拷贝的是「指向同一个缓冲的把手」 |

所以：**想改调用方的 Vec / Map，直接改就行**（`v.push(x)`、`m.set(k, v)`），
不用传指针；但**把参数整个换掉**（`v = Vec<i64>[]`）外面照样看不见 ——
那只是让本地的把手指向别处。想改结构体，要么返回一个新结构体，
要么用 `new` 出一个指针传进去（见 [14](#14-指针与-new)）。

### 8.3 递归

递归、互递归都正常用：

```fa
fn fib(n: i64) -> i64:
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)

fn is_even(n: i64) -> bool:
    if n == 0 { return true }
    return is_odd(n - 1)

fn is_odd(n: i64) -> bool:
    if n == 0 { return false }
    return is_even(n - 1)

fn deep(n: i64) -> i64:
    if n <= 0 { return 0 }
    return 1 + deep(n - 1)

fn main() -> i64:
    print("fib(20) =", fib(20))
    print("is_even(10) =", is_even(10), " is_odd(10) =", is_odd(10))
    print("10 万层递归 =", deep(100000))
    return 0
```

```text
fib(20) = 6765
is_even(10) = true  is_odd(10) = false
10 万层递归 = 100000
```

**能有多深**：默认 8MB 栈下，十几万层没问题（上面 10 万层跑得好好的），
再深就会撞穿栈。撞穿时运行时打一句人话再以非零码退出，不会静默消失：

```text
panic: 栈溢出（递归太深 / 局部变量太大）
```

FA **没有尾调用优化**，`return f(x)` 这种尾递归照样占一层栈。
所以「层数和输入规模成正比」的递归（遍历链表、深度优先搜索、逐层展开）
能写成 `while` / `for` 就写成循环；递归留给天然分形的场合（树、分治）。
每一帧很大的函数（局部有大数组）也要留神，栈是按帧大小算的。

### 8.4 返回值

`return` 后面的括号可有可无，`return (a + b)` 和 `return a + b` 一样：

```fa
fn add1(n: i64) -> i64:
    return (n + 1)

fn main() -> i64:
    print(add1(41))
    return 0
```

```text
42
```

声明了返回类型的函数，`return` 就必须带值：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn f() -> i64:
    return

fn main() -> i64:
    print(f())
    return 0
```

```text
类型错误 (行 3, 列 5): 函数声明返回 i64，但 return 没有值
        return
        ^
```

**走完函数体却没命中任何 return，不是错误** —— 编译器在结尾补一个
**零值**返回（这是 [7.6](#76-match多路分支) 里 match 漏分支时会发生的事）：

```fa
struct P:
    x: i64
    y: i64

fn fs() -> str:
    if false { return "不会走到" }

fn fv() -> Vec<i64>:
    if false { return Vec<i64>[1] }

fn fp() -> P:
    if false { return P{x: 1, y: 2} }

fn main() -> i64:
    let s = fs()
    print("str:", "[" + s + "]", s.len())
    let v = fv()
    print("Vec:", v.to_str(), v.len())
    v.push(7)
    print("  还能正常用:", v.to_str())
    let p = fp()
    print("struct:", p.x, p.y)
    return 0
```

```text
str: [] 0
Vec: [] 0
  还能正常用: [7]
struct: 0 0
```

| 返回类型 | 掉到末尾时得到 |
|---|---|
| i64 / 其它整数 | `0` |
| f64 / f32 | `0.0` |
| bool | `false` |
| str | `""`（空串，长度 0） |
| `Vec<T>` | 空表（之后 `push` 正常） |
| `Map<K, V>` | 空字典（之后 `set` 正常） |
| struct | 各字段全零 |
| enum | 第 0 个变体 |
| 指针 | `nil` |

这条路也是**定义良好**的：defer 照跑、局部引用照释放、拿到的空容器还能接着用，
不会段错误。但它多半意味着你漏了一个分支 —— 想让它变成硬错误，就在函数末尾
`assert(false, "不该走到这")`（见 [18](#18-错误处理与运行时安全网)）。

### 8.5 函数是一等值

函数名不加括号就是一个**函数指针**，可以存进变量、当参数传、装进容器：

```fa
fn add3(n: i64) -> i64:
    return n + 3

fn twice(f: fn(i64) -> i64, v: i64) -> i64:
    return f(f(v))

fn greet(name: str):
    print("你好,", name)

fn main() -> i64:
    let g: fn(i64) -> i64 = add3
    print(g(1), twice(add3, 1), twice(g, 1))

    let fs = Vec<fn(i64) -> i64>[]
    fs.push(add3)
    fs.push(g)
    print("装在 Vec 里:", fs[0](10), fs[1](20), fs.len())

    let h: fn(str) = greet
    h("世界")
    return 0
```

```text
4 7 7
装在 Vec 里: 13 23 2
你好, 世界
```

函数类型写作 `fn(参数类型, ...) -> 返回类型`，没有返回值就省掉箭头（`fn(str)`）。
类型标注可以省（`let g = add3` 也行），但**当参数传**的时候，参数声明里必须写清楚。

两件事做不到：

**函数指针不能是 `nil`**（`nil` 的类型是 `*u8`，和函数类型不是一回事）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let g: fn(i64) -> i64 = nil
    print(g(1))
    return 0
```

```text
类型错误 (行 3, 列 5): 变量初始化: 类型不匹配，期望 fn(i64)->i64，实际 *u8
        let g: fn(i64) -> i64 = nil
        ^
```

**没有 lambda，也没有闭包**：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn main() -> i64:
    let g = |x| x + 1
    print(g(1))
    return 0
```

```text
语法错误 (行 3, 列 13): 无法解析的表达式起始 token '|'
        let g = |x| x + 1
                ^
```

要「一小段能当值传的逻辑」，就写一个具名函数（顶层或嵌套都行）；
要「带状态」，把状态当参数传进去，或者用全局变量 / 一个结构体装起来。

### 8.6 嵌套函数

函数体里可以再定义函数。实现方式是**提升**：内层函数变成一个普通的顶层函数
（符号名是 `外层__内层`），所以它能调用别的函数、能递归、能当函数指针传，
也能调用兄弟嵌套函数：

```fa
fn outer(n: i64) -> i64:
    fn square(x: i64) -> i64:
        return x * x

    fn cube(x: i64) -> i64:
        return square(x) * x        # 调用兄弟嵌套函数

    return cube(n) + square(n)

fn main() -> i64:
    print(outer(5))
    return 0
```

```text
150
```

代价是：内层函数**看不见外层的局部变量**（因为提升之后它就是个顶层函数，
外层那一帧早没了）：

```fa
# ❌ 这段是故意的：编译不过，报错见下
fn outer(n: i64) -> i64:
    fn inner(x: i64) -> i64:
        return x + n
    return inner(1)

fn main() -> i64:
    print(outer(5))
    return 0
```

```text
类型错误 (行 4, 列 20): 嵌套函数不能捕获外层局部变量 'n'（FA 还没有闭包：把它当参数传进去，或把函数提到顶层）
            return x + n
                       ^
```

报错里已经把出路说了：**当参数传进去**。

```fa
fn outer(n: i64) -> i64:
    fn inner(x: i64, base: i64) -> i64:
        return x + base

    return inner(1, n)

fn main() -> i64:
    print(outer(5))
    return 0
```

```text
6
```

还有一条容易忽略的：既然是提升，**写在哪个块里都一样**。下面这个 `inner`
定义在 `if` 块里，条件不成立它也照样存在、照样能调用：

```fa
fn main() -> i64:
    if 1 > 0:
        fn inner(x: i64) -> i64:
            return x * 2
    print(inner(21))
    return 0
```

```text
42
```

别指望用 `if` 来「有条件地定义函数」。嵌套函数适合的是**只在这个函数里用得到**
的辅助逻辑（一段排序的比较、一个递归的辅助过程），写在这儿是为了让读者知道
它跟外面无关，不是为了限制它的作用域。

### 8.7 这一节的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 同名函数定义两次报错 | 没有重载 | 换名字，或用 `match` 在函数里分派 |
| `fn f() -> (i64, str)` 报错 | 没有元组 / 多重返回值 | 定义一个结构体返回 |
| `fn f(n: i64 = 1)` 报错 | 没有默认参数 | 再写一个 `f_default()` |
| `f(x = 3)` 报错 | 没有具名实参 | 按位置传，参数名写清楚 |
| 函数里改了 Vec / Map，外面也变了 | 引用计数，共享同一个缓冲 | 想隔离就先拷一份（见 [9](#9-vec会变长的列表)） |
| 函数里改了 struct，外面没变 | struct 是整份拷贝 | 返回新值，或用 `new` 传指针 |
| `v = Vec<i64>[]` 在函数里不影响外面 | 只是让本地把手指向别处 | 用 `v.clear()` 清原表 |
| 参数没写 `mut` 也能改 | 参数本来就是自己那一份 | 想表达「不改」就自己别改 |
| `return` 不带值报错（非 void 函数） | 声明了返回类型就得给值 | 补值，或把返回类型去掉 |
| 函数没命中 return 也编译通过 | 结尾补零值 | 末尾 `assert(false, "...")` 拦住 |
| 深递归报「栈溢出」 | 8MB 栈，且没有尾调用优化 | 改成循环；或拆小问题规模 |
| `let g: fn(i64) -> i64 = nil` 报错 | nil 是 `*u8`，不是函数 | 函数指针必须指向真函数 |
| `\|x\| x + 1` 报错 | 没有 lambda | 写具名函数（嵌套也行） |
| 嵌套函数读外层变量报错 | 提升成顶层函数，没有闭包 | 当参数传进去 |
| `if` 块里定义的函数外面也能调 | 嵌套函数一律提升 | 别用 `if` 控制「是否定义」 |
