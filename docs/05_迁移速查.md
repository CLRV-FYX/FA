# 从其他语言迁移到 FA

同一件事在各语言里怎么写。左边是你熟悉的语言，右边是 FA。

---

## 1. 从 Python 过来

| Python | FA |
|---|---|
| `print("hi")` | `print("hi")` |
| `x = 1` | `let x = 1` |
| `def f(a, b): return a+b` | `fn f(a: i64, b: i64) -> i64: return a + b` |
| `if x > 0:` | `if x > 0:` （一样） |
| `for i in range(10):` | `for i in 0..10:` |
| `for x in items:` | `for x in items:` （一样） |
| `while cond:` | `while cond:` （一样） |
| `f"{name} is {age}"` | `"{name} is {age}"` |
| `len(s)` | `len(s)` |
| `s.upper(), s.split(",")` | `s.upper(), s.split(",")` |
| `lst.append(x)` | `v.push(x)` |
| `lst.pop()` | `v.pop()` |
| `d["k"] = 1` | `m["k"] = 1`（或 `m.set("k", 1)`） |
| `d["k"]` | `m["k"]`（或 `m.get("k")`；键不存在时返回 0 / nil，不抛异常） |
| `import numpy` | `use py` + `py.import("numpy")` |
| `//` 整除 | `/` （整数相除自动整除） |
| `**` 幂 | `**` （一样） |
| `and / or / not` | `and / or / not` （一样） |
| `# 注释` | `#` 或 `//` |

**主要区别**

1. 函数参数**必须写类型**：`fn add(a: i64, b: i64) -> i64`。这是 FA 能跑得快的根本原因。
2. 变量声明用 `let`（之后可以直接 `x = 2` 重新赋值，不用 `nonlocal` 之类的东西）。
3. 缩进用冒号 `:` 开头，也可以用 `{}`（随你习惯）。
4. 没有 `None`，用 `nil`；没有动态类型，`if x:` 要写成 `if x != 0:`。
5. 速度：同样的算法，FA 通常比 Python **快 4 ~ 180 倍**。

## 2. 从 C 过来

| C | FA |
|---|---|
| `int x = 1;` | `let x = 1` |
| `printf("%d\n", x)` | `print(x)` |
| `int f(int a){ return a; }` | `fn f(a: i64) -> i64: return a` |
| `for (i=0;i<n;i++)` | `for i in 0..n:` 或 `for (let i = 0; i < n; i = i + 1):` |
| `while (c) {}` | `while c:` |
| `struct P { int x; };` | `struct P: x: i64` |
| `p.x` | `p.x` （一样） |
| `&x` / `*p` | `&x` / `p[0]` |
| `int a[10];` | `let a: [i64; 10] = [...]` |
| `a[0]` | `a[0]` （一样） |
| `malloc/free` | **不需要**（自动引用计数） |
| `#include <stdio.h>` | `use c "stdio.h":` |
| `/* 注释 */` | `/* */` 或 `//` 或 `#` |

**主要区别**

1. 没有头文件、没有声明/定义分离。
2. 没有 `malloc/free`，也没有悬垂指针（引用计数）。
3. 数组越界**一定会报错**，不是未定义行为。
4. 字符串是带长度的对象，不是 `char*`（但传给 C 时自动转）。
5. 可以直接写 `asm """..."""` 逃生。

## 3. 从 Java 过来

| Java | FA |
|---|---|
| `int x = 1;` | `let x = 1` |
| `System.out.println(x)` | `print(x)` |
| `int f(int a){ return a; }` | `fn f(a: i64) -> i64: return a` |
| `if (c) { }` | `if c:` |
| `for (int i=0;i<n;i++)` | `for i in 0..n:` 或 C 风格 `for (let i = 0; i < n; i = i + 1):` |
| `class P { int x; }` | `struct P: x: i64` （数据） |
| `p.method()` | `p.method()` （方法写在 `impl P:` 里） |
| `List<Integer> l` | `let v = Vec<i64>[]` |
| `l.add(x)` | `v.push(x)` |
| `Map<String,Integer> m` | `Map<str, i64>` |
| `m.put(k,v)` / `m.get(k)` | `m.set(k,v)` / `m.get(k)` |
| `switch (x) { case 1: }` | `match x: 1: ...` （不用写 break） |
| `enum Color { Red }` | `enum Color: Red` |
| `// 注释` | `//` 或 `#` |

**主要区别**

1. 没有类继承、没有接口（有 `struct` + `impl` 方法、有 `enum` + `match`）。
2. 没有垃圾回收停顿：引用计数在编译期插入，对象离开作用域立即释放。
3. 所有 Java 类库都能用：`use java` + `java.class("java.util.ArrayList")`。
4. 基本类型就是基本类型，没有装箱开销。

## 4. 从 Go 过来

| Go | FA |
|---|---|
| `var x int = 1` / `x := 1` | `let x = 1` |
| `func f(a int) int {}` | `fn f(a: i64) -> i64:` |
| `fmt.Println(x)` | `print(x)` |
| `for i := 0; i < n; i++` | `for i in 0..n:` |
| `for _, v := range xs` | `for v in xs:` |
| `[]int{1,2,3}` | `[1, 2, 3]` 或 `Vec<i64>[1,2,3]` |
| `append(xs, v)` | `xs.push(v)` |
| `map[string]int{}` | `Map<str, i64>()` |
| `struct P { X int }` | `struct P: x: i64` |
| `func (p P) M() {}` | `impl P: fn m(self):` |
| `defer f()` | `defer f()` （一样） |

## 5. 从 Rust 过来

| Rust | FA |
|---|---|
| `let x = 1;` | `let x = 1` |
| `let mut y = 1;` | `let y = 1` （默认可改，没有 mut） |
| `fn f(a: i64) -> i64 {}` | `fn f(a: i64) -> i64:` |
| `println!("{}", x)` | `print(x)` |
| `format!("{x}")` | `"{x}"` |
| `for i in 0..10` | `for i in 0..10:` （一样） |
| `for i in 0..=10` | `for i in 0..=10:` （一样） |
| `vec![1,2,3]` | `Vec<i64>[1,2,3]` |
| `v.push(x)` | `v.push(x)` （一样） |
| `struct P { x: f64 }` | `struct P: x: f64` |
| `impl P { fn m(&self) {} }` | `impl P: fn m(self):` |
| `enum C { Red }` | `enum C: Red` |
| `match c { C::Red => ... }` | `match c: C.Red: ...` |
| `&x` / `*p` | `&x` / `p[0]` |
| `String::from("a")` | `"a"` |

**主要区别**

1. **没有借用检查器**：不用和编译器搏斗，代价是你要自己避免把栈地址存到更长寿的地方。
2. 内存管理是**编译期插入的引用计数**，不是所有权。
3. 没有 `unwrap()` 的地狱：越界、空值会直接报明确的错误并退出。
4. 没有 trait / 泛型函数（有泛型容器 `Vec<T>` / `Map<K,V>`）。

## 6. 速记：最容易踩的 5 个坑

| 现象 | 原因 | 解决 |
|---|---|---|
| `7 / 2` 得到 `3` 不是 `3.5` | 整数除法 | 写成 `7.0 / 2.0` 或 `7 / 2 as f64` |
| 函数定义报"未知类型" | 参数没写类型 | `fn f(x: i64)` |
| `str(x)` 报类型错误 | 表达式类型不对 | 用 `str(x)` 只对数字有效；对象用 `x.to_str()` |
| Vec 里的浮点算错 | 已修复（0.1.0 起容器按位存储 f64） | 升级即可 |
| 中文输出乱码 | 终端编码 | 终端改成 UTF-8；Python 侧已自动设为 UTF-8 |
