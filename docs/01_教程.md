> 零基础入门的分册。系统学请读 **[08_完全教程.md](08_完全教程.md)**（官方教学文档，29 节，示例全部实测）。

这一篇不需要任何编程基础。如果你看得懂"把数字加起来"这件事，你就能学会 FA。

---

## 第 0 步：准备

```bash
chmod +x bin/fa                 # 只需要做一次（让 fa 变成可执行命令）
export PATH=$PWD/bin:$PATH
fa version                      # 看到版本信息就说明装好了
```

新建一个文件 `hi.fa`，内容：

```fa
fn main() -> i64:
    print("你好, FA!")
    return 0
```

运行：

```bash
fa run hi.fa
```

你会看到 `你好, FA!`。

**这一行行是什么意思？**

- `fn main() -> i64:` —— 定义一个叫 `main` 的函数，它是程序的入口；`-> i64` 表示它会返回一个整数。
- 缩进的下一行是函数"里面"要做的事（**FA 用缩进来表示层级，就像写文章分段**）。
- `print(...)` —— 打印内容并换行。
- `return 0` —— 程序结束，返回 0（0 表示"一切正常"）。

> 💡 如果你习惯 C/Java 的大括号，也可以写成：
> ```fa
> fn main() -> i64 {
>     print("你好, FA!");
>     return 0;
> }
> ```
> 两种写法**完全等价**，你可以在同一个文件里混用。这是 FA 的"双模式语法"。

## 第 1 步：变量

```fa
fn main() -> i64:
    let age = 18          # 整数
    let pi = 3.14159      # 小数
    let name = "小明"      # 字符串
    let ok = true         # 布尔（真 / 假）

    print(name, "今年", age, "岁")
    print("π ≈", pi, "，对吗？", ok)
    return 0
```

- 用 `let 名字 = 值` 创建变量。**不需要写类型**，FA 会自己推断。
- 想重新赋值，直接写 `age = 20`（不需要 `mut`）。
- 想明确指定类型，写 `let x: f64 = 1`（`:f64` 表示"这是一个小数"）。

**常用类型**：

| 类型 | 说明 | 例子 |
|---|---|---|
| `i64` | 整数（默认） | `42`、`-7` |
| `f64` | 小数（默认） | `3.14` |
| `bool` | 真/假 | `true` / `false` |
| `str` | 文本 | `"你好"` |
| `char` | 单个字符 | `'A'` |

整数还有 `i8 i16 i32 u8 u32 u64`（小整数省内存），小数还有 `f32`。一般写 `i64` / `f64` 就好。

## 第 2 步：算数与比较

```fa
fn main() -> i64:
    print(1 + 2 * 3)        # 7   （先乘除后加减）
    print((1 + 2) * 3)      # 9   （括号优先）
    print(7 / 2)            # 3   ← 整数除以整数，结果是整数
    print(7 % 2)            # 1   ← 余数
    print(2 ** 10)          # 1024 ← 幂
    print(7.0 / 2.0)        # 3.5 ← 小数除法得到小数

    print(10 > 3, 10 < 3)   # true false
    print(5 == 5, 5 != 5)   # true false
    print(true and false)   # false
    print(true or false)    # true
    return 0
```

位运算也有：`&`（与）、`|`（或）、`^`（异或）、`<<` `>>`（移位）。

## 第 3 步：做决定（if）

fn main() -> i64:

        print("优秀")
    elif score >= 60:
        print("及格")

`elif` 就是"否则如果"。可以有任意多个。

## 第 4 步：重复（循环）

### while：只要条件成立就一直做

```fa
fn main() -> i64:
    let i = 0
    let total = 0
    while i < 100:
        total = total + i
        i = i + 1
    print("0~99 的和 =", total)     # 4950
    return 0
```

### for：遍历一组东西

```fa
fn main() -> i64:
    for i in 0..5:          # 0,1,2,3,4（不含 5）
        print(i)
    for i in 1..=5:         # 1,2,3,4,5（含 5）
        print(i)

    let names = Vec<str>["苹果", "香蕉"]
    for n in names:         # 遍历容器
        print(n)
    return 0
```

### 跳出 / 跳过

```fa
    while true:
        let line = read_line()
        if line == "quit":
            break           # 跳出循环
        if line == "":
            continue        # 直接进入下一轮
        print("你输入了:", line)
```

### C/Java 风格的 for（老朋友专属）

```fa
fn main() -> i64 {
    for (let i = 0; i < 10; i = i + 1) {
        print(i);
    }
    return 0;
}
```

## 第 5 步：函数

```fa
fn add(a: i64, b: i64) -> i64:      # 两个参数，返回整数
    return a + b

fn greet(who: str):                  # 没有 -> 表示不返回值
    print("你好,", who)

fn fib(n: i64) -> i64:               # 递归：函数自己调用自己
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

fn main() -> i64:
    print(add(3, 4))        # 7
    greet("世界")
    print(fib(20))          # 6765
    return 0
```

参数要写类型：`a: i64`。不返回值的函数可以省略 `->`。

## 第 6 步：文本处理

```fa
fn main() -> i64:
    let s = "FA 语言"

    print(len(s))                  # 9   字节长度
    print(s + " 很棒")              # 拼接
    print(s.slice(0, 2))           # FA   取一段
    print(s.upper(), s.lower())    # 大/小写
    print(s.contains("语言"))       # true
    print(s.find("语"))             # 3    出现位置，找不到返回 -1
    print(s.replace("语言", "世界")) # 替换

    let parts = "a,b,c".split(",") # 切成数组
    print(len(parts), parts.get(2))# 3 c

    # 字符串插值：把变量直接写进 { }
    let n = 21
    print("{n} 的两倍是 {n * 2}")    # 21 的两倍是 42

    # 多行文本用三个引号
    let poem = """
    床前明月光，
    疑是地上霜。
    """
    print(poem)
    return 0
```

## 第 7 步：装东西的容器

### Vec：可以变长的列表

```fa
fn main() -> i64:
    let v = Vec<i64>[1, 2, 3]      # 创建
    v.push(4)                      # 追加
    print(len(v))                  # 4    长度
    print(v.get(0))                # 1    按下标取
    v.set(0, 100)                  # 修改
    print(v.get(0))                # 100
    print(v.pop())                 # 4    取出并删除最后一个
    print(v.contains(2))           # true

    let total = 0
    for x in v:
        total = total + x
    print(total)
    return 0
```

### Map：键值字典

```fa
fn main() -> i64:
    let m = Map<str, i64>()
    m.set("苹果", 5)
    m.set("香蕉", 3)
    print(m.get("苹果"))    # 5
    print(m.has("香蕉"))    # true
    print(len(m))          # 2
    m.del("苹果")
    for k in m:            # 遍历所有键
        print(k, m.get(k))
    return 0
```

### 数组：定长、更快

```fa
    let a: [i64; 5] = [10, 20, 30, 40, 50]
    print(a[0], a[4])       # 10 50
    a[2] = 300
    print(a[2])             # 300
```

## 第 8 步：自定义类型（结构体）

```fa
struct Student:
    name: str
    age: i64
    score: f64

impl Student:                          # 给 Student 加方法
    fn level(self) -> str:
        if self.score >= 90:
            return "优秀"
        return "普通"

    fn grow(self):                     # 修改自己
        self.age = self.age + 1

fn main() -> i64:
    let s = Student { name: "小明", age: 18, score: 95.5 }
    print(s.name, s.age, s.level())    # 小明 18 优秀
    s.grow()
    print(s.age)                       # 19
    return 0
```

## 第 9 步：枚举与模式匹配

```fa
enum Color:
    Red
    Green
    Blue

fn to_cn(c: Color) -> str:
    match c:                 # 像 switch，但不会漏写 break
        Color.Red:
            return "红"
        Color.Green:
            return "绿"
        Color.Blue:
            return "蓝"

fn main() -> i64:
    let c = Color.Green
    print(to_cn(c))          # 绿

    let n = 2
    match n:
        1:
            print("一")
        2:
            print("二")
        _:                   # _ 表示"其它所有情况"
            print("很多")
    return 0
```

## 第 11 步：调用别的语言写的库

这是 FA 最大的优势。

```fa
use c "stdio.h":                    # C：直接声明就能用
    fn printf(fmt: *u8, ...) -> i32

use py                              # Python：整个生态都是你的
use java                            # Java：JDK 和 Maven 生态

fn main() -> i64:
    printf("C 说: %d\n", 42)

    let np = py.import("numpy")
    py.exec("print('numpy:', __import__('numpy').arange(10).sum())")

    let math = java.class("java.lang.Math")
    print(java.call_i64(math, "max", "(II)I", 3, 7))   # 7
    return 0
```

## 第 12 步：内存是怎么管的？

**你什么都不用做。** FA 在编译时就插入了引用计数：

```fa
fn main() -> i64:
    let i = 0
    while i < 1000000:
        let big = "很长很长的字符串" + str(i)   # 每轮都新建一个字符串
        i = i + 1                              # big 在这里自动释放
    print("完成，没有内存泄漏")                   # 循环结束后所有临时对象都已回收
    return 0
```

规则很简单：

1. 每个对象记住"有几个人在用我"。
2. 变量离开 `{}` 或缩进块时，自动减一。
3. 减到 0 就自动释放。

所以 **没有 malloc/free，没有垃圾回收停顿，也没有 Rust 的借用检查器要打**。
