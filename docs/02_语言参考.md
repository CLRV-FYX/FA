## 1. 词法

### 1.1 两种语法模式

FA 同时支持**缩进模式**和**大括号模式**，可以在同一个文件里混用：

```fa
fn f() -> i64:                  fn g() -> i64 {
    let x = 1                       let x = 1;
    if x > 0:                       if (x > 0) {
        return x                        return x;
    return 0                        }
}                                   return 0;
                                }
```

规则：

- 缩进模式：冒号 `:` 开始一个块，块内缩进必须一致（默认 4 空格，Tab 视为 4）。
- 大括号模式：语句用 `;` 分隔。
- 括号 `() [] {}` 内部的换行不产生缩进层级。

### 1.2 注释

```fa
# 井号注释（Python 风格）
// 双斜杠注释（C 风格，推荐，因为 # 在字符串插值里更常用）
/* 块注释 */
```

### 1.3 标识符与关键字

标识符由字母、数字、下划线组成，区分大小写，支持 UTF-8（`let 名字 = "小明"` 合法）。

保留字：`fn let mut const return if elif else while for in loop break continue
struct enum match use as extern defer true false nil and or not new impl pub
sizeof typeof unsafe cxx py java libc static where raise try catch asm ref move dyn trait mod`

这些字里，**在用的**是：`fn let mut const return if elif else while for in loop break
continue struct enum match use as extern defer true false nil and or not new impl pub
sizeof asm raise cxx py java libc`（`mut` 只是风格标注，`pub` 只是给人看的标记，
两者都不改变语义；`sizeof` 是编译期常量；`raise "消息"` 等价于 `panic("消息")`；
`unsafe { ... }` 目前就是个普通块）。**只占了位置、写了报语法错误**的是：
`typeof static where try catch ref move dyn trait mod`。

### 1.4 字面量

```fa
42          # 整数（默认 i64）
0xFF 0b1010 0o17          # 十六进制 / 二进制 / 八进制
1_000_000   # 下划线分隔，提高可读性
3.14  1e6  2.5e-3         # 小数（默认 f64）
42i8  3.5f32              # 带后缀指定类型
'A'  '\n'  '\x41'  '\u0041'   # 字符（单字节 u8）
"你好"  "\u4F60\u{597D}"   # 字符串（UTF-8）
"""多行
文本"""                    # 三引号多行字符串
[1, 2, 3]                 # 数组字面量
```

转义序列：`\n \t \r \a \b \f \\ \' \" \0 \xNN \uNNNN \u{NNNN}`
（`\u4F60` 与 `\u{4F60}` 等价；花括号形式位数不限，`"\u{1F600}"` 是 😀）。
写了别的（`"\q"`）是**编译错误**，不会默默留下反斜杠。

> `char` 就是**一个字节**（u8），所以 `'\u4F60'` 会被拒绝并提示改用字符串
> `"\u4F60"` —— 你（U+4F60）在 UTF-8 里占 3 个字节。

### 1.5 字符串插值

在普通双引号字符串里用 `{表达式}`：

```fa
let n = 21
print("{n} 的两倍是 {n * 2}")     # 21 的两倍是 42
print("{s.upper()}!")             # 表达式里可以调用方法
print("{m["k"]}")                 # 表达式里可以再写字符串字面量
```

`{}` 里可以出现引号、下标、方法调用、条件表达式（`{if n > 10 { "大" } else { "小" }}`）。

三条规则：

- **`{{` 和 `}}` 是字面花括号**（和 Python / Rust / C# 一个规矩）：`"{{n}}"` 打出来是
  `{n}`；要「花括号包住值」就写 `"{{{n}}}"`（→ `{42}`）。`\{` / `\}` 等价，两种随你挑。
  所以打 JSON、打结构体那种文本不必再靠 `chr(123)` / 拼接绕路：`"{{\"k\": 1}}"` 就是
  `{"k": 1}`。
- `{}` 空着是编译错误（不是打印两个花括号）；要一对空花括号写 `{{}}`。
- 插值的 `{` 没有配对的 `}`，报的是「字符串里的插值 { 没有配对的 }（要打印一个真的花括号，
  写 {{ 和 }}）」；以前报「字符串未闭合」，位置指着字符串开头，看不出是花括号的事。

字符串不会自动和其它类型相加（`"a" + 1` 报错）；插值或 `str(x)` / `x.to_str()` 才是正道。
数字字面量后面也能直接跟方法：`42.to_str()` 是 `"42"`。

## 2. 类型系统

### 2.1 基础类型

| 类型 | 字节 | 说明 |
|---|---|---|
| `i8 i16 i32 i64` | 1/2/4/8 | 有符号整数 |
| `u8 u16 u32 u64` | 1/2/4/8 | 无符号整数 |
| `isize usize` | 8 | 指针宽度的整数 |
| `f32 f64` | 4/8 | 浮点数 |
| `bool` | 1 | `true` / `false` |
| `char` | 1 | 单个字节（UTF-8 的一个字节） |
| `str` | 8(指针) | UTF-8 字符串，带长度与引用计数 |
| `void` | — | 没有返回值 |

### 2.2 复合类型

| 写法 | 说明 |
|---|---|
| `*T` | 指针，如 `*i64`、`*u8` |
| `[T; N]` | 定长数组，如 `[i64; 10]` |
| `Vec<T>` | 动态数组（引用计数） |
| `Map<K, V>` | 哈希表（引用计数） |
| `struct` 名 | 结构体，值类型 |
| `enum` 名 | 枚举，值类型 |
| `fn(A, B) -> R` | 函数类型（可赋给变量、当参数传递；不捕获环境） |
| `T?` | 可选类型，**只用于指针/引用类型**（等价于 `*T`，可以是 `nil`） |

`Vec<Vec<i64>>`、`Map<str, Vec<Point>>` 这类嵌套类型参数可以直接写，`>>` 不会被当成移位运算符。

`Map<K, V>` 的 **K 只能是按内容哈希、按内容比较的类型**：`str`、整数、浮点、`bool`、
`char`、指针。结构体、枚举、容器不能当键 —— 它们在容器里存的是**装箱指针**，
哈希的是地址而不是内容，于是 `m.set(p, 1)` 之后拿一个字段相同的 `p` 去 `get` 永远查不到。
编译器会直接拒绝并说清楚：

```console
$ fa check m.fa
类型错误 (行 11, 列 13): Map 的键不能是 P：键要能按内容哈希和比较，只有 str / 整数 / 浮点 / bool / char / 指针可以（结构体、枚举在容器里存的是装箱指针，哈希的是地址：set 完再 get 查不到，程序退出时还会 free 出错）。想按结构体查，就用它那个唯一字段当键，或者用 Vec 自己找
```

> **已知限制**：标量 `f32` 在运算时会被提升为 `f64`（单精度目前只影响结构体字段布局与 C 函数签名）。
> 需要「有或没有」的语义而值不是指针时，用枚举：`enum Opt: None / Some(v: i64)`。
> 也就是说 `let x: f32 = 1.5` 得到的变量参与计算时是双精度的。

### 2.3 类型转换

```fa
let a = 3.7
let b = a as i64          # 3   截断
let c = b as f64          # 3.0
let s = str(42)           # "42"
let n = i64("123")        # 123
let f = f64("1.5")        # 1.5
```

数字之间用 `as`，字符串与数字之间用 `str()` / `i64()` / `f64()`。

### 2.4 类型推断

`let x = 1` 推断为 `i64`，`let y = 1.0` 推断为 `f64`。
需要别的类型请写标注：`let z: f32 = 1.0`。

## 3. 运算符

按优先级从低到高：

| 级别 | 运算符 |
|---|---|
| 范围 | `..` `..=` |
| 逻辑 | `or` `and` |
| 位 | `\|` `^` `&` |
| 相等 | `==` `!=` |
| 比较 | `<` `<=` `>` `>=` |
| 移位 | `<<` `>>` |
| 加减 | `+` `-` |
| 乘除 | `*` `/` `%` |
| 幂 | `**` |

要点：

- **整数 `/` 整数 = 整数**（向零截断），`-7 / 2 == -3`、`-7 % 2 == -1`（与 C 一致）。
- 只要有一边是小数，结果就是小数。
- `**` 是幂，`2 ** 10 == 1024`。
- 复合赋值：`+= -= *= /= %= &= |= ^= <<= >>=`。
- `char` 参与算术/比较时按 C 的整型提升处理，结果是 `i64`：
  `s[i] - 'A'`、`chr(b - 'A' + 'a')`（大小写转换）、`b >= '0' and b <= '9'` 都能直接写。

## 4. 变量

```fa
let x = 10              # 推断 i64
let y: f64 = 1          # 显式类型（1 会自动转成 1.0）
x = 20                  # 重新赋值，不需要 mut
let (a, b) = (1, 2)     # 元组解构（支持）
```

**作用域**：块结束即释放（引用计数归零时）。花括号本身就是一条语句，
可以凭空开一个新作用域：

```fa
{
    let tmp = compute()      # 出了这个块 tmp 就释放了
    total += tmp
}
```

**类型标注能驱动容器字面量**：标注明明写了 `Vec`，就不必再写一遍构造器。

```fa
let v: Vec<i64> = []           # 等价 Vec<i64>()
let w: Vec<i64> = [1, 2, 3]    # 等价 Vec<i64>[1, 2, 3]
let a: [i64; 3] = [1, 2, 3]    # 没有标注时，[1, 2, 3] 仍是定长数组
```

### 全局变量（顶层 `let`）

写在任何函数之外的 `let` 是**全局可变变量**：全程序唯一一份存储，
哪个函数都能读写（`const` 则是编译期常量，每次用到都重新求值一遍初值）。

```fa
let counter = 0                 # 类型推断
let ratio: f64 = 1.5            # 显式标注
let zeros: i64                  # 只标注不初始化 -> 零值
let names = Vec<str>["甲"]       # 容器也行
let memo = Map<i64, i64>()

fn bump(n: i64):
    counter += n                # 任何函数都能改
    names.push("新增{n}")

fn main() -> i64:
    bump(5)
    print(counter, names.len())  # 5 2
    return 0
```

- 初值在 `main` 的第一条语句之前**按声明顺序**执行一次；初值里可以调用函数、
  用 `const` 和别的全局，但没有 `self`、不能 `return`。
- 引用计数类型（`str` / `Vec` / `Map`）可以反复覆盖，旧值会被正确释放。
- 局部变量同名时**局部优先**（和 C / Python 一致）。
- `&全局` 能拿到它的地址，可以直接交给 C 函数写。
- 支持标量、`str`、`Vec`、`Map`、数组；结构体/枚举是值类型，暂时给明确的编译期错误
  （改用 `Vec<P>` / `Map` / 指针，或把字段拆成几个全局）。

## 5. 控制流

```fa
if 条件:
    ...
elif 条件:
    ...
else:
    ...

while 条件:
    ...
    break / continue

loop:                   # 无限循环
    ...

for x in 0..10:         # 不含 10
for x in 0..=10:        # 含 10
for x in 数组 / Vec / Map / str:
for (let i = 0; i < n; i = i + 1):      # C 风格

match 值:
    模式1:
        ...
    模式2:
        ...
    _:                  # 默认分支
        ...
```

关于 `..` / `..=`：

- range **不是一等值**，只能写在 `for` 的遍历位置。`print(0..10)`、`let r = 0..10`
  都是编译错误（会告诉你改用 `Vec<i64>` 或直接 `for`）。
- **没有步进**：`0..10..2` 会被解析成 `(0..10)..2` 并当场报错。要跳着走用
  `for i in 0..10 { let j = i * 2 }` 或 `while`。
- 端点必须是整数 / `bool` / `char`（`for c in 97..100` 配 `chr(c)` 可以遍历字母）；
  `0.0..3.0`、`"a".."z"` 会报错，不会悄悄截断。
- 起点大于终点就是**空循环**（`10..0` 一次都不执行），不会倒着走。

`match` 可以是：字面量、枚举变体（`Color.Red` 或裸写 `Red`）、`_` 通配。

分支体有三种等价写法，可以混用：

```fa
match c:
    Color.Red: return "红"           # 单行
    Color.Green(n):                  # 缩进块（变体载荷自动绑定到 n）
        return "绿{n}"
match c { _: print("其它") }         # 花括号形式（分支之间不用分隔符）
```

`if` / `while` / `for` 的块同样支持单行写法：`if x > 0: return 1`。

### 5.1 if / match 当表达式用

分支的**值 = 块里最后一条表达式语句**（和 Rust 一样，不用写 `return`）：

```fa
let a = if n > 1 { 10 } else { 20 }
let b = if n > 5 { 1 } else if n > 1 { 2 } else { 3 }
let s = match n {
    0: "零"
    1: "一"
    _: "多"
}
print(if n == 2 { "是的" } else { "不是" })     # 也能直接当实参

let g = if n > 1 { if n > 3 { "很大" } else { "大" } } else { "小" }   # 可以嵌套

# 结构体 / 枚举 / 数组也行
let pt = if ok { Point { x: 1, y: 2 } } else { origin() }
let xs = match n { 0: [1, 2, 3] _: [9, 9, 9] }
```

规则：

| 情况 | 结果 |
|---|---|
| `if` 没有 `else` | 报错（可能没有值） |
| `match` 没有 `_`，且不是「枚举变体全覆盖」 | 报错 |
| 各分支类型不同 | 都是数值时统一（有浮点就 `f64`，否则 `i64`）；指针之间互转；`nil` 分支跟随另一边的指针类型；其它组合报错 |
| 分支以 `return` / `break` / `continue` / `panic(...)` 结尾 | 该分支「发散」，不需要值，也不参与类型统一 |
| 结果是 `struct` / `enum` / 数组 | 支持：分支里新建的值把所有权**移交**给结果，来自变量的则拷一份并逐字段加引用 |

```fa
let h = if n < 0 { return 1 } else { n * 3 }    # 发散分支：合法
let p: *i64 = if n > 1 { &x } else { nil }      # nil 跟随 *i64
```

> 头部表达式后面紧跟的 `{` 一律是**块**的开始：`if done { ... }`、`while ok { ... }`、
> `for x in items { ... }`、`match v { ... }` 都不会被误当成结构体字面量。
> 真要在条件里写结构体字面量，加括号：`if (P { x: 1 }).x > 0 { ... }`。

遍历：`for x in 容器` 对 Vec / 数组 / Map（遍历键）/ str（遍历字节）都成立，
元素是结构体或枚举时会拷贝一份（Vec 里的结构体元素则是指向装箱对象的引用）。

## 6. 函数

```fa
fn 名字(参数: 类型, ...) -> 返回类型:
    ...
    return 值
```

- 不返回值可以省略 `-> 返回类型`，或写 `-> void`。
- **递归**完全支持（有尾调用之外的正常栈帧开销）。
- 参数最多 6 个走寄存器，更多自动走栈，无需关心。
- 可变参数（用于 C 互操作）：`fn printf(fmt: *u8, ...) -> i32`。
- **函数可以嵌套定义**，实现方式是提升成一个独立函数（符号名 `fa_外层__内层`）：
  能递归、能调用兄弟嵌套函数、能当函数指针传、能返回结构体，方法里也能写。
  但它**不能捕获外层局部变量**（FA 还没有闭包）—— 真要传值就当参数传，
  写了会在语义阶段报错并说明原因：

```fa
fn outer(n: i64) -> i64:
    fn square(x: i64) -> i64:      # ✅ 提升成 fa_outer__square
        return x * x
    fn bad(x: i64) -> i64:
        return x + n               # ❌ 嵌套函数不能捕获外层局部变量 'n'
    return square(n)
```

### defer

```fa
fn run():
    defer print("最后执行")
    print("先执行")
```

`defer` 的语句会在**当前块结束时**执行（后进先出）。

## 7. 结构体与方法

```fa
struct 名字:
    字段: 类型
    字段: 类型

impl 名字:
    fn 方法(self, 参数) -> 类型:      # self 可以裸写，也可以用 self: 名字
        ...
```

- 结构体是**值类型**：`let b = a` 会拷贝一份。
- 方法里改 `self.x` 会改到原对象（因为 `self` 是指针）。
- 构造：`Point { x: 1.0, y: 2.0 }`。没有默认值的字段**都要写**（缺了会在语义阶段报错）。
- 字段可以写**默认值**，于是字面量里能省略它：

```fa
struct Task:
    name: str                  # 没默认值 -> 必须写
    prio: i64 = 3
    tags: Vec<str> = []
    code: i64 = next_id()      # 默认值里可以调用函数、用 const / 全局

let t = Task { name: "写测试" }          # prio=3, tags=空表, code=next_id()
let u = Task { name: "改代码", prio: 1 }  # 只覆盖一部分
```

  默认值在**每次构造时重新求值**，所以 `tags: Vec<str> = []` 给每个对象各自的空表，
  不是所有对象共享一个（引用计数也各自一份）。花括号写法还支持逗号分隔字段：
  `struct P { a: i64 = 1, b: i64 }`。
- 方法可以有任意个参数、也可以返回结构体：

```fa
struct Point:
    x: f64 = 0.0
    y: f64 = 0.0

impl Point:
    fn shifted(self, dx: f64, dy: f64) -> Point:      # 返回聚合值走 sret
        return Point { x: self.x + dx, y: self.y + dy }

let p = Point { x: 1.0, y: 2.0 }.shifted(0.5, 0.5)    # Point { x: 1.5, y: 2.5 }
```

- impl 里**不带 self** 的方法是「静态」方法，用类型名调用（工厂函数的常见写法）：

```fa
struct Point:
    x: f64 = 0.0
    y: f64 = 0.0

impl Point:
    fn origin() -> Point:                  # 没有 self
        return Point { x: 0.0, y: 0.0 }
    fn of(x: f64, y: f64) -> Point:
        return Point { x: x, y: y }

let a = Point.origin()
let b = Point.of(3.0, 4.0)
```

  和普通方法唯一的区别就是没有 self 可传：调用写 `Point.of(3.0, 4.0)`（类型名 + `.` + 方法名），
  参数照名字对位。静态方法和普通方法可以混在同一个 impl 里，顺序随意。

- 结构体可以自引用（链表、树），但**只能通过指针**：

```fa
struct Node:
    val: i64
    next: *Node            # ✅
    # inner: Node          # ❌ 按值包含自己 = 无限大小，语义阶段报错
```

## 8. 枚举

```fa
enum 名字:
    变体A                        # 无载荷
    变体B(n: i64)                # 带载荷（多个字段视为内联的匿名结构体）
    变体C(s: str, t: f64)
```

内存布局是 `{ i64 tag; 载荷 }`，所以枚举是**聚合类型**（和结构体一样按值拷贝）。

使用：

```fa
let c = Color.Green              # 变体构造器
match c:
    Color.Red:  ...
    Green:      ...              # 也可以直接写变体名
    Color.Green(n): print(n)     # 载荷绑定成局部变量
```

枚举也能有 `impl` 方法（`self` 就是枚举值），载荷同样可以用 `*Enum` 递归：

```fa
enum List:
    Nil
    Cons(v: i64, next: *List)
```

`match` 不要求穷尽：没有分支命中就什么都不做（想要兜底请写 `_`）。
返回浮点的分支也正确（曾经有个 bug：浮点常量返回值被当成整数返回）。

## 9. 指针与数组

```fa
let x = 41
let p = &x                       # 取地址，类型 *i64
print(p[0])                      # 读（等价于 *p）
p[0] = 42                        # 写

let a: [i64; 5] = [1,2,3,4,5]
print(a[0], len(a))
let q = &a[0]                    # 数组首元素地址（可直接传给 C）
```

指针算术：`p[1]` 等价于 C 的 `*(p+1)`。

指向结构体的指针可以**直接点出字段**（自动解引用，等于 C 的 `->`）：

```fa
struct Node:
    val: i64

fn bump(n: *Node, k: i64):
    n.val = n.val + k            # 等价于 (*n).val

let p = new Node { val: 1 }      # new：在堆上放一份，返回 *Node
bump(p, 2)
print(p.val, p[0].val, (*p).val) # 三种写法都是 3
free(p)                          # new 出来的要自己还（先还字段引用，再还内存）
```

`free(p)` 只接受指针：它先把 `p` 指向对象自己拥有的引用逐个还掉（结构体 / 枚举字段里的
`str`、`Vec`，数组元素），再调 `fa_free`。引用计数的 `str` / `Vec` / `Map` 不需要也不能
`free`（写了会编译报错）。对 C 那边 `malloc` 出来的 `*u8`，`free` 等价于 libc 的 `free`。

### 下标

四种容器都支持下标读写，越界会触发运行时错误（中文报错 + 非零退出码）：

```fa
let a = [1, 2, 3]                # 数组
a[0] = 9

let v: Vec<i64> = []             # 空的 [] 从标注里取元素类型，等价于 Vec<i64>()
push(v, 10)
print(v[0])                      # 等价 v.get(0)
v[0] = 20                        # 等价 v.set(0, 20)

let m = Map<str, i64>()          # 空表
let m2 = Map<str, i64>["a": 1, "b": 2]     # 带初值的字面量（也可以写 Map<str,i64>[]）
m["k"] = 1                       # 等价 m.set("k", 1)
print(m["k"])                    # 等价 m.get("k")
for k in m2.keys(): print(k, m2[k])        # keys() / values() 方法与全局形式都有

let s = "hello"
print(s[0], s.len)               # 'h' 5 —— 注意取的是**字节**（char = u8）
s[0] = 'H'                       # ❌ str 不可变（字面量在只读段）
```

## 10. 内存模型

FA 使用**编译期插入的引用计数**：

| 场景 | 行为 |
|---|---|
| 对象创建（`Vec`、`Map`、运行时产生的字符串） | 引用计数 = 1 |
| `let b = a`（引用类型） | 计数 +1 |
| 变量离开作用域 | 计数 -1 |
| 计数归零 | 立即释放 |
| 字符串字面量 | 永生（计数为 -1，不参与回收） |
| 循环内产生的临时对象 | **每次迭代结束就释放**，不会累积 |

容器（`Vec` / `Map` / 含引用字段的结构体）内部元素的引用计数由运行时自动维护，
`push` / `set` / `del` 都会正确处理新旧值的生命周期。

> ⚠️ 唯一需要注意的：不要把栈上对象的地址存到生命周期更长的地方（FA 不做借用检查）。

## 11. 模块与互操作

```fa
use "math.fa"                    # 导入另一个 FA 文件的顶层声明（可嵌套、自动防循环）

use c "stdio.h":                 # 声明 C 函数
    fn printf(fmt: *u8, ...) -> i32

use cxx "cpp/x.hpp" lib "cpp/libx.so":     # C++：自动生成 extern "C" shim
    fn add(a: i32, b: i32) -> i32

use py                           # 启用内嵌的 CPython
use java                         # 启用内嵌的 JVM
use lib "./mylib.so":            # 运行时 dlopen
    fn my_func(x: i64) -> i64
```

`str` 传给 `*u8` 参数时会自动转成 C 字符串指针；`char*`（`*u8`）传回 `str` 参数时会自动包装成字符串。
反过来，`s.cstr()` 拿到的就是**裸指针**（类型 `*u8`，不加引用计数），只适合马上交给 C 函数用。

### FA 自己的多文件模块

```fa
// math.fa
const TAU: f64 = 6.283185307
fn circle_area(r: f64) -> f64:
    return TAU * r * r / 2.0

// main.fa
use "math.fa"                    # 路径相对于当前文件
fn main() -> i64:
    print(circle_area(2.0))      # 导入的声明直接进入当前文件，没有命名空间前缀
    return 0
```

- 被导入的文件里 `struct` / `impl` / `enum` / `const` / `fn` 全部可用，它自己也能再 `use`。
- 循环导入不会死循环（同一个文件只展开一次）；文件不存在会报清楚路径。
- 不支持 `use "x.fa" as m` 的别名写法，也没有 `use std.xxx` 这样的标准库模块
  （内建的 `print` / `len` / `Vec` / `Map` 直接可用，不需要导入）。
- 顶层重名（两个同名 `fn`、或导入的文件与当前文件撞名）会在语义阶段报错并给出两处行号。

### 函数指针

```fa
fn add1(x: i64) -> i64:
    return x + 1

fn apply(f: fn(i64) -> i64, x: i64) -> i64:
    return f(x)

fn main() -> i64:
    let f: fn(i64) -> i64 = add1
    print(f(41))                 # 42
    f = add1                     # 可以重新赋值
    print(apply(add1, 1))        # 2
    return 0
```

函数指针**不捕获环境**（FA 还没有闭包）：要传状态就把状态放进结构体，另写一个方法。

## 12. 错误处理

```fa
assert(条件)                     # 条件为假则打印位置并退出（退出码 1）
assert(条件, "提示信息")
panic("出错了")                  # 主动终止

```

## 13. 内嵌汇编

需要极致控制时可以直接写汇编（原样插入，不做寄存器校验）：

```fa
asm """
    rdtsc
    shl rdx, 32
    or  rax, rdx
"""
```

> 这是"逃生舱"：编译器不会检查你的汇编是否破坏了寄存器。
> 只建议在性能关键的小段里使用，且用完恢复被调用者保存的寄存器（`rbx r12-r15 rbp`）。

## 15. 暂不支持的写法

下面这些写法解析器/语义分析会直接报错，别在这上面浪费时间：

| 写法 | 状况 | 替代 |
|---|---|---|
| `let f = (x) => x + 1` / 闭包 | 没有闭包，函数值不捕获环境 | 顶层 `fn` + 函数指针；要带状态就用结构体 + 方法 |
| 嵌套函数捕获外层局部变量 | 嵌套 `fn` 已支持，但是**提升**实现的，没有环境可捕获 | 把值当参数传进去，或用全局 / 结构体带状态 |
| `trait` / `interface` / 泛型 `fn f<T>(x: T)` | 未实现 | 每种类型各写一个 `impl`；容器有 `Vec<T>` / `Map<K,V>` |
| 顶层 `let` 是结构体/枚举 | 标量 / `str` / `Vec` / `Map` / 数组都支持，值类型暂不支持 | `Vec<P>` / `Map` / 指针，或把字段拆成几个全局 |
| `s[0] = 'H'`（改字符串字节） | `str` 不可变（字面量在只读数据段） | 用 `Vec<char>`，或 `s.replace(...)` 生成新串 |
| `S { a: 1 }` 省略**没有默认值**的字段 | 写了 `x: i64 = 3` 的字段才能省 | 给字段加默认值，或补齐（`str` 字段给 `""`） |
| `use "x.fa" as m` | 没有命名空间/别名 | 直接 `use "x.fa"`，声明进入当前文件 |
| `use std.io` 之类 | 没有可导入的标准库模块 | 内建函数直接可用（见 03_标准库.md） |
| `let m = {}`（空 Map 字面量） | `{}` 已经是「空块」，无法两义 | `Map<K, V>()` 或 `Map<K, V>[]` |
| 按码点索引的 `s[i]` | `s[i]` 取的永远是**字节**（`char` = u8） | `s.char_at(i)` / `s.char_len()` / `s.codepoints()` / `s.slice_chars(a,b)` |

报错信息都会带**行号、列号、源码片段和插入符**；编译期能查出来的（类型不匹配、
字段不存在、重复定义、导入文件找不到、括号没闭合、extern 函数按值收发结构体）
都不会拖到运行时。

> C / C++ 互操作另有一组限制（结构体只能按指针传、`str` 与 `char*` 的自动转换规则、
> 容器不能出现在 extern 声明里），见 `04_互操作.md`。
