## 1. 词法

### 1.1 两种语法模式

FA 同时支持**缩进模式**和**大括号模式**，可以在同一个文件里混用：

```fa
fn f() -> i64:                  fn g() -> i64 {
    let x = 1                       let x = 1;
    if x > 0:                       if (x > 0) {
        return x                        return x;
    return 0                        }
}                                   return 0;
                                }
```

规则：

- 缩进模式：冒号 `:` 开始一个块，块内缩进必须一致（默认 4 空格，Tab 视为 4）。
- 大括号模式：语句用 `;` 分隔。
- 括号 `() [] {}` 内部的换行不产生缩进层级。

### 1.2 注释

```fa
# 井号注释（Python 风格）
// 双斜杠注释（C 风格，推荐，因为 # 在字符串插值里更常用）
/* 块注释 */
```

### 1.3 标识符与关键字

标识符由字母、数字、下划线组成，区分大小写，支持 UTF-8（`let 名字 = "小明"` 合法）。

保留字：`fn let mut const return if elif else while for in loop break continue
struct enum match use as extern defer true false nil and or not new impl pub
sizeof typeof unsafe cxx py java libc static where raise try catch asm ref move dyn trait mod`

### 1.4 字面量

```fa
42          # 整数（默认 i64）
0xFF 0b1010 0o17          # 十六进制 / 二进制 / 八进制
1_000_000   # 下划线分隔，提高可读性
3.14  1e6  2.5e-3         # 小数（默认 f64）
42i8  3.5f32              # 带后缀指定类型
'A'  '\n'  '\u4F60'       # 字符
"你好"                     # 字符串（UTF-8）
"""多行
文本"""                    # 三引号多行字符串
[1, 2, 3]                 # 数组字面量
```

字符串转义：`\n \t \r \\ \" \0 \xNN \uNNNN`。

### 1.5 字符串插值

在普通双引号字符串里用 `{表达式}`：

```fa
let n = 21
print("{n} 的两倍是 {n * 2}")     # 21 的两倍是 42
print("{s.upper()}!")             # 表达式里可以调用方法
```

## 2. 类型系统

### 2.1 基础类型

| 类型 | 字节 | 说明 |
|---|---|---|
| `i8 i16 i32 i64` | 1/2/4/8 | 有符号整数 |
| `u8 u16 u32 u64` | 1/2/4/8 | 无符号整数 |
| `isize usize` | 8 | 指针宽度的整数 |
| `f32 f64` | 4/8 | 浮点数 |
| `bool` | 1 | `true` / `false` |
| `char` | 1 | 单个字节（UTF-8 的一个字节） |
| `str` | 8(指针) | UTF-8 字符串，带长度与引用计数 |
| `void` | — | 没有返回值 |

### 2.2 复合类型

| 写法 | 说明 |
|---|---|
| `*T` | 指针，如 `*i64`、`*u8` |
| `[T; N]` | 定长数组，如 `[i64; 10]` |
| `Vec<T>` | 动态数组（引用计数） |
| `Map<K, V>` | 哈希表（引用计数） |
| `struct` 名 | 结构体，值类型 |
| `enum` 名 | 枚举，值类型 |
| `fn(A, B) -> R` | 函数类型 |

> **已知限制**：标量 `f32` 在运算时会被提升为 `f64`（单精度目前只影响结构体字段布局与 C 函数签名）。
> 也就是说 `let x: f32 = 1.5` 得到的变量参与计算时是双精度的。

### 2.3 类型转换

```fa
let a = 3.7
let b = a as i64          # 3   截断
let c = b as f64          # 3.0
let s = str(42)           # "42"
let n = i64("123")        # 123
let f = f64("1.5")        # 1.5
```

数字之间用 `as`，字符串与数字之间用 `str()` / `i64()` / `f64()`。

### 2.4 类型推断

`let x = 1` 推断为 `i64`，`let y = 1.0` 推断为 `f64`。
需要别的类型请写标注：`let z: f32 = 1.0`。

## 3. 运算符

按优先级从低到高：

| 级别 | 运算符 |
|---|---|
| 范围 | `..` `..=` |
| 逻辑 | `or` `and` |
| 位 | `\|` `^` `&` |
| 相等 | `==` `!=` |
| 比较 | `<` `<=` `>` `>=` |
| 移位 | `<<` `>>` |
| 加减 | `+` `-` |
| 乘除 | `*` `/` `%` |
| 幂 | `**` |

要点：

- **整数 `/` 整数 = 整数**（向零截断），`-7 / 2 == -3`、`-7 % 2 == -1`（与 C 一致）。
- 只要有一边是小数，结果就是小数。
- `**` 是幂，`2 ** 10 == 1024`。
- 复合赋值：`+= -= *= /= %= &= |= ^= <<= >>=`。

## 4. 变量

```fa
let x = 10              # 推断 i64
let y: f64 = 1          # 显式类型（1 会自动转成 1.0）
x = 20                  # 重新赋值，不需要 mut
let (a, b) = (1, 2)     # 元组解构（支持）
```

**作用域**：块结束即释放（引用计数归零时）。

## 5. 控制流

```fa
if 条件:
    ...
elif 条件:
    ...
else:
    ...

while 条件:
    ...
    break / continue

loop:                   # 无限循环
    ...

for x in 0..10:         # 不含 10
for x in 0..=10:        # 含 10
for x in 数组 / Vec / Map / str:
for (let i = 0; i < n; i = i + 1):      # C 风格

match 值:
    模式1:
        ...
    模式2:
        ...
    _:                  # 默认分支
        ...
```

`match` 可以是：字面量、枚举变体（`Color.Red` 或裸写 `Red`）、`_` 通配。

## 6. 函数

```fa
fn 名字(参数: 类型, ...) -> 返回类型:
    ...
    return 值
```

- 不返回值可以省略 `-> 返回类型`，或写 `-> void`。
- **递归**完全支持（有尾调用之外的正常栈帧开销）。
- 参数最多 6 个走寄存器，更多自动走栈，无需关心。
- 可变参数（用于 C 互操作）：`fn printf(fmt: *u8, ...) -> i32`。
- 函数可以嵌套定义（闭包式的局部函数）。

### defer

```fa
fn run():
    defer print("最后执行")
    print("先执行")
```

`defer` 的语句会在**当前块结束时**执行（后进先出）。

## 7. 结构体与方法

```fa
struct 名字:
    字段: 类型
    字段: 类型

impl 名字:
    fn 方法(self, 参数) -> 类型:      # self 可以裸写，也可以用 self: 名字
        ...
```

- 结构体是**值类型**：`let b = a` 会拷贝一份。
- 方法里改 `self.x` 会改到原对象（因为 `self` 是指针）。
- 构造：`Point { x: 1.0, y: 2.0 }`（字段名可省略顺序以外的写法暂不支持）。

## 8. 枚举

```fa
enum 名字:
    变体A
    变体B
```

使用：

```fa
let c = Color.Green              # 变体构造器
match c:
    Color.Red:  ...
    Green:      ...              # 也可以直接写变体名
```

## 9. 指针与数组

```fa
let x = 41
let p = &x                       # 取地址，类型 *i64
print(p[0])                      # 读（等价于 *p）
p[0] = 42                        # 写

let a: [i64; 5] = [1,2,3,4,5]
print(a[0], len(a))
let q = &a[0]                    # 数组首元素地址（可直接传给 C）
```

指针算术：`p[1]` 等价于 C 的 `*(p+1)`。

## 10. 内存模型

FA 使用**编译期插入的引用计数**：

| 场景 | 行为 |
|---|---|
| 对象创建（`Vec`、`Map`、运行时产生的字符串） | 引用计数 = 1 |
| `let b = a`（引用类型） | 计数 +1 |
| 变量离开作用域 | 计数 -1 |
| 计数归零 | 立即释放 |
| 字符串字面量 | 永生（计数为 -1，不参与回收） |
| 循环内产生的临时对象 | **每次迭代结束就释放**，不会累积 |

容器（`Vec` / `Map` / 含引用字段的结构体）内部元素的引用计数由运行时自动维护，
`push` / `set` / `del` 都会正确处理新旧值的生命周期。

> ⚠️ 唯一需要注意的：不要把栈上对象的地址存到生命周期更长的地方（FA 不做借用检查）。

## 11. 模块与互操作

```fa
use c "stdio.h":                 # 声明 C 函数
    fn printf(fmt: *u8, ...) -> i32

use cxx "cpp/x.hpp" lib "cpp/libx.so":     # C++：自动生成 extern "C" shim
    fn add(a: i32, b: i32) -> i32

use py                           # 启用内嵌的 CPython
use java                         # 启用内嵌的 JVM
use lib "./mylib.so":            # 运行时 dlopen
    fn my_func(x: i64) -> i64
```

`str` 传给 `*u8` 参数时会自动转成 C 字符串指针；`char*`（`*u8`）传回 `str` 参数时会自动包装成字符串。

## 12. 错误处理

```fa
assert(条件)                     # 条件为假则打印位置并退出（退出码 1）
assert(条件, "提示信息")
panic("出错了")                  # 主动终止

let x = 数组[100]                # 越界：运行时报错并退出，不是未定义行为
```

退出码：`fa_exit(码)` 立即退出。

## 13. 内嵌汇编

需要极致控制时可以直接写汇编（原样插入，不做寄存器校验）：

```fa
asm """
    rdtsc
    shl rdx, 32
    or  rax, rdx
"""
```

> 这是"逃生舱"：编译器不会检查你的汇编是否破坏了寄存器。
> 只建议在性能关键的小段里使用，且用完恢复被调用者保存的寄存器（`rbx r12-r15 rbp`）。
